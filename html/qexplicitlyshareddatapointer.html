Detailed Description

QExplicitlySharedDataPointer<T> shares a QSharedData-derived object like QSharedDataPointer does, but never detaches implicitly: modifying the data through any pointer modifies it for all of them. Call detach() to make a private copy explicitly.

See also QSharedData and QSharedDataPointer.

Differences from Qt

It has no move constructor or move assignment, no reset(), swap(), constData() or operator!(), and no adopting constructor. The conversion to bool is implicit.

void QExplicitlySharedDataPointer::detach()

Detaches from shared data. If the data is shared with another pointer, it is copied and this pointer refers to the copy. Does nothing for a null pointer.
