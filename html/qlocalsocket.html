Detailed Description

Connect to a QLocalServer by name, then read and write as with any QIODevice:

QLocalSocket socket;
socket.connectToServer("my-service");
socket.write("hello");

A relative name is placed in QDir::tempPath(); a name starting with / is used as the socket path.

See also QLocalServer.

Differences from Qt

Connecting either succeeds or fails before connectToServer() returns, so the socket never stays in ConnectingState. Linux and other POSIX systems only, using Unix domain sockets.

[override] bool QLocalSocket::waitForBytesWritten(int msecs = 30000)

Reimplements QIODevice::waitForBytesWritten().

Waits up to msecs milliseconds until pending data has been written. A negative value waits forever. Returns true if all of it was written.

See also flush().

bool QLocalSocket::waitForConnected(int msecs = 30000)

Returns true if the socket is connected. Connecting finishes inside connectToServer(), so this never waits; msecs is ignored.

See also connectToServer().

bool QLocalSocket::waitForDisconnected(int msecs = 30000)

Waits up to msecs milliseconds for the socket to disconnect. A negative value waits forever. Returns true if it disconnected.

See also disconnectFromServer().

[override] bool QLocalSocket::waitForReadyRead(int msecs = 30000)

Reimplements QIODevice::waitForReadyRead().

Waits up to msecs milliseconds for data to read, handling it as the event loop would. A negative value waits forever. Returns true if data arrived.

See also readyRead().
