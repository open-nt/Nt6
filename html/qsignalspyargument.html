Detailed Description

It stands in for QVariant, which Nt does not have yet. Code like spy.at(0).at(0).toInt() and spy.at(0).at(0).value<MyType>() reads the same as with Qt.

See also QSignalSpy.

Differences from Qt

This class does not exist in Qt, where the arguments are QVariant objects. Write auto arguments = spy.takeFirst(); rather than naming QList<QVariant>. Only numbers and enums convert to one another.
