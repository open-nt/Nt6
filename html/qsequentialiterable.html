Detailed Description

A QVariant that holds a sequential container, such as QList<int>, std::vector<QString>, QSet or QStringList, converts to a QSequentialIterable. It reads the elements as QVariant objects without knowing the container type:

QVariant v = QVariant::fromValue(QList<int>{1, 2, 3});
if (v.canConvert<QSequentialIterable>()) {
    QSequentialIterable it = v.value<QSequentialIterable>();
    for (const QVariant &e : it)
        qDebug() << e.toInt();
}

The element type must be registered with QMetaType, which happens automatically for the types Nt knows and for types that are declared with Q_DECLARE_METATYPE().

See also QAssociativeIterable, QVariant and QMetaType.

Differences from Qt

The iterable works on a copy of the variant, so it is read-only: there is no addValue(), removeValue() or mutableBegin(). There is no metaContainer(), and canReverseIterate() is always true.
