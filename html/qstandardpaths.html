Detailed Description

The class locates the directories where a program should keep documents, configuration, cache and other data, following the XDG base directory specification. All functions are static.

const QString dir = QStandardPaths::writableLocation(QStandardPaths::AppDataLocation);
const QString exe = QStandardPaths::findExecutable("git");

Differences from Qt

Only the XDG layout of Linux and other POSIX systems is supported. The application sub-directory is the executable's file name, since QCoreApplication has no applicationName() or organizationName() yet. There is no setTestModeEnabled() or isTestModeEnabled(), and displayName() returns untranslated English names.

Member Function Documentation

[static] QString QStandardPaths::displayName(StandardLocation type)

Returns a human-readable, untranslated English name for the location type.

[static] QString QStandardPaths::findExecutable(const QString &executableName, const QStringList &paths = QStringList())

Finds an executable file named executableName and returns its absolute path, or an empty string if none is found. If executableName contains a slash it is tested directly. Otherwise each directory in paths is searched, or in the PATH environment variable if paths is empty.

[static] QString QStandardPaths::locate(StandardLocation type, const QString &fileName, LocateOptions options = LocateFile)

Finds the first entry named fileName in the standard locations of the given type that matches options. Returns its full path, or an empty string if there is none. If fileName is empty, the location directory itself is tested.

See also locateAll() and standardLocations().

[static] QStringList QStandardPaths::locateAll(StandardLocation type, const QString &fileName, LocateOptions options = LocateFile)

Finds every entry named fileName in the standard locations of the given type that matches options. Returns their full paths in search order.

See also locate() and standardLocations().

[static] QStringList QStandardPaths::standardLocations(StandardLocation type)

Returns all directories of the given type, with the writable location first. The result does not contain empty or duplicate entries, and the directories are not checked for existence.

See also writableLocation() and locateAll().

[static] QString QStandardPaths::writableLocation(StandardLocation type)

Returns the directory where files of the given type should be written, or an empty string if the location cannot be determined. The directory is not created.

See also standardLocations() and locate().
