Detailed Description

A QByteArrayView refers to a contiguous range of bytes without owning or copying it, so the viewed data must outlive the view. It is cheap to copy and is meant for function parameters that only read bytes, accepting a QByteArray, a string literal or a std::string_view alike.

A view is null if it was constructed without data (or from a null QByteArray), and empty if its size is 0. A null view is also empty.

See also QByteArray and QStringView.

Differences from Qt

Only part of the Qt API is provided: construction, element access, slicing, startsWith(), endsWith(), indexOf(), lastIndexOf(), contains(), compare() and the comparison operators. There are no number conversions (toInt() and friends), count(), split(), trimmed(), truncate(), chop() or reverse iterators. first(), last(), sliced() and chopped() do not check their arguments.

QByteArrayView QByteArrayView::mid(qsizetype pos, qsizetype len = -1) const

Returns a view of len bytes starting at index position pos. If len is negative or extends past the end, the view extends to the end. A negative pos is clamped to 0 and reduces len accordingly. If pos is past the end, an empty view is returned.

See also left(), right() and sliced().
