Detailed Description

A data stream is a binary stream of encoded information that is independent of the host's operating system, CPU and byte order. The format is compatible with Qt's QDataStream: numbers are big-endian by default, a QString is written as UTF-16 code units behind a byte-length prefix, and a null QString or QByteArray is written as the length 0xFFFFFFFF.

Write values with << and read them back, in the same order, with >>:

QByteArray bytes;
QDataStream out(&bytes, QIODevice::WriteOnly);
out << qint32(42) << QString("text");

QDataStream in(bytes);
qint32 number;
QString text;
in >> number >> text;

Read and write errors are recorded in status() instead of being reported by return values. Reading a QList, QMap or QHash clears the container if an error occurs. Enumerations are streamed as their underlying integer type.

See also QTextStream, QIODevice, QBuffer and QFile.

Differences from Qt

Container sizes are quint32 only; the 64-bit extended size used by stream version 21 (Qt 6.7) for more than 0xFFFFFFFD elements is neither written nor read. Writing such a size sets SizeLimitExceeded. The transaction API (startTransaction() and friends) is not implemented. Streams of version 1 (Qt 1.x Latin-1 strings) are not special-cased. Streaming is supported for the built-in numbers, QString, QChar, QByteArray, QList, QMap, QHash and enumerations only.

enum QDataStream::Status

Describes the state of the stream.

ConstantDescription
QDataStream::OkThe stream is operating normally.
QDataStream::ReadPastEndThe stream has read past the end of the data in the device.
QDataStream::ReadCorruptDataThe stream read corrupt data, such as a string with an odd byte length.
QDataStream::WriteFailedThe stream cannot write to the underlying device.
QDataStream::SizeLimitExceededThe stream cannot write the data because its size exceeds the format's 32-bit limit.

Constructs a data stream that operates on the byte array array, which must outlive the stream. The stream owns an internal QBuffer opened with the given mode (QIODevice::ReadOnly, QIODevice::WriteOnly or QIODevice::ReadWrite). Written data is stored in array.

QDataStream & QDataStream::operator>>(char *&s)

This is an overloaded function.

Reads a length-prefixed byte string from the stream, allocates a buffer with new char[] for it and stores the pointer in s. The string is null-terminated. The caller must free it with delete[]. s is nullptr if the string is empty or an error occurs.

See also readBytes().

QDataStream & QDataStream::readBytes(char *&s, qint64 &len)

Reads the buffer s from the stream and returns a reference to the stream.

The buffer s is allocated using new char[], and null-terminated. Ownership passes to the caller, who must free it with delete[]. The length of the data, not counting the terminator, is stored in len. Both are cleared to nullptr and 0 if the length is zero or if an error occurs.

The data is expected in the format written by writeBytes().

See also readRawData() and writeBytes().

int QDataStream::readRawData(char *s, int len)

Reads at most len bytes from the stream into s and returns the number of bytes read, or -1 if there is no device or len is negative. If fewer than len bytes could be read, the status is set to ReadPastEnd. The bytes are read as they are, with no length prefix and no byte order conversion.

See also readBytes(), writeRawData() and skipRawData().

int QDataStream::skipRawData(int len)

Skips len bytes from the stream and returns the number of bytes actually skipped, or -1 if there is no device or len is negative. If fewer than len bytes could be skipped, the status is set to ReadPastEnd.

See also readRawData().

QDataStream & QDataStream::writeBytes(const char *s, qint64 len)

Writes the length specifier len and the buffer s to the stream and returns a reference to the stream.

The len is serialized as a quint32, followed by len bytes from s. If len is negative or too large for a quint32, nothing is written and the status is set to SizeLimitExceeded.

See also writeRawData() and readBytes().

int QDataStream::writeRawData(const char *s, int len)

Writes len bytes from s to the stream and returns the number of bytes written, or -1 if there is no device, the stream is in an error state or len is negative. If the device does not accept all the bytes, the status is set to WriteFailed. The bytes are written as they are, with no length prefix and no byte order conversion.

See also writeBytes() and readRawData().
