Detailed Description

To send a type of your own, give it stream operators and register it with qDBusRegisterMetaType(). A structure maps to a D-Bus structure with beginStructure() and endStructure():

struct Fix { double lat; double lon; };
Q_DECLARE_METATYPE(Fix)

QDBusArgument &operator<<(QDBusArgument &arg, const Fix &fix) {
    arg.beginStructure();
    arg << fix.lat << fix.lon;
    arg.endStructure();
    return arg;
}
const QDBusArgument &operator>>(const QDBusArgument &arg, Fix &fix) {
    arg.beginStructure();
    arg >> fix.lat >> fix.lon;
    arg.endStructure();
    return arg;
}

qDBusRegisterMetaType<Fix>();

Containers, structures and dictionaries of a received message that Nt has no C++ type for arrive in a QVariant as a QDBusArgument. qdbus_cast() turns one into a type that is registered:

QVariantMap map = qdbus_cast<QVariantMap>(reply.arguments().first());

A QDBusArgument that was default-constructed is for writing; one that came from a message is for reading. Reading from a copy does not move the position of the original.

See also QDBusMetaType, QDBusVariant and QDBusMessage.

Differences from Qt

The stream operators for QDate, QTime, QDateTime and the geometry types are missing. A std::pair takes the place of QPair, and std::tuple maps to a structure as well. Marshalling long and unsigned long is supported because Nt's qint64 is long on Linux. A value of the wrong type is not read: the function prints a warning, returns a default value and skips the value on the wire.

ConstantDescription
