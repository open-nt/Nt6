Detailed Description

A file descriptor can travel in a message to a process on the same machine, if both ends of the connection support it; see QDBusConnection::connectionCapabilities(). The object owns the descriptor it holds and closes it when the last copy is destroyed:

QFile log("/var/log/app.log");
log.open(QIODevice::ReadOnly);
iface.call("Watch", QVariant::fromValue(QDBusUnixFileDescriptor(log.handle())));

See also QDBusConnection::connectionCapabilities().
