Detailed Description

Parse a URL from text, or build one a component at a time:

QUrl url("https://user@example.com:8080/a%20b?q=1#top");
url.host();                // "example.com"
url.port();                // 8080
url.path();                // "/a b"

QUrl built;
built.setScheme("http");
built.setHost("example.com");
built.setPath("/a b");
built.toString();          // "http://example.com/a b"
built.toEncoded();         // "http://example.com/a%20b"

Use resolved() to combine a base URL with a relative reference, following RFC 3986.

See also QUrlQuery.

Differences from Qt

Internationalized host names are lower-cased but not converted to or from Punycode, so ace_encoded helpers do not exist. Formatting options cover the common removal flags; PreferLocalFile, RemoveFilename and the individual delimiter-decoding flags are absent. There is no setIdnWhitelist() or fromUserInput().

Member Type Documentation

enum QUrl::ComponentFormattingOption

Selects how a component is returned.

ConstantDescription
QUrl::PrettyDecodedReadable, keeping escapes that would change the meaning.
QUrl::FullyEncodedPercent-encoded, as on the wire.
QUrl::FullyDecodedEvery escape decoded.

typedef QUrl::ComponentFormattingOptions

The ComponentFormattingOptions type is a typedef for QFlags<ComponentFormattingOption>. It stores an OR combination of ComponentFormattingOption values.

typedef QUrl::FormattingOptions

The FormattingOptions type is a typedef for QFlags<UrlFormattingOption>. It stores an OR combination of UrlFormattingOption values.

enum QUrl::ParsingMode

Selects how input text is interpreted.

ConstantDescription
QUrl::TolerantModeFixes common mistakes, escaping characters that are not allowed.
QUrl::StrictModeRejects anything that is not a valid URL.
QUrl::DecodedModeTreats the input as plain text and escapes it, so % is literal.

enum QUrl::UrlFormattingOption

Selects what toString() and adjusted() leave out or change.

ConstantDescription
QUrl::NoneThe URL as it is.
QUrl::RemoveSchemeLeaves out the scheme.
QUrl::RemovePasswordLeaves out the password.
QUrl::RemoveUserInfoLeaves out the user name and password.
QUrl::RemovePortLeaves out the port.
QUrl::RemoveAuthorityLeaves out the whole authority.
QUrl::RemovePathLeaves out the path.
QUrl::RemoveQueryLeaves out the query.
QUrl::RemoveFragmentLeaves out the fragment.
QUrl::StripTrailingSlashRemoves a trailing slash from the path.
QUrl::NormalizePathSegmentsRemoves . and .. segments from the path.
