Detailed Description

See also QNetworkAccessManager and QNetworkReply.

Differences from Qt

Attributes are stored and returned, but none of them changes how the request is sent; setRedirectPolicy(), setMaximumRedirectsAllowed() and setTransferTimeout() cover the common settings. Known headers are read and written as QByteArray rather than QVariant. There is no priority or HTTP/2 setting, and no UserVerifiedRedirectPolicy.

enum QNetworkRequest::RedirectPolicy

Selects what happens when the server redirects a request.

ConstantDescription
QNetworkRequest::ManualRedirectPolicyRedirects are not followed; the 3xx reply is returned.
QNetworkRequest::NoLessSafeRedirectPolicyRedirects are followed, but not to a less secure scheme.
QNetworkRequest::SameOriginRedirectPolicyOnly redirects to the same scheme, host and port are followed.
