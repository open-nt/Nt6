Detailed Description

const auto certificates = QSslCertificate::fromPath("server.pem");
qDebug() << certificates.first().subjectDisplayName();

See also QSslKey and QSslConfiguration.

Differences from Qt

There is no verify(), isBlacklisted(), extensions(), publicKey(), toText() or PKCS#12 import. fromPath() takes a single file, not a wildcard pattern.
