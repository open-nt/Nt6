Detailed Description

A JSON object is a list of key-value pairs, where the keys are unique strings and the values are QJsonValue. A QJsonObject can be converted to and from a QJsonDocument.

QJsonObject o;
o.insert("name", "Nt");
o["version"] = 6;
for (auto it = o.begin(); it != o.end(); ++it)
    use(it.key(), it.value());

The keys are kept sorted, so keys(), the iterators and the JSON text a document writes all list them in that order, not in the order in which they were inserted. A key is a QString and is compared by UTF-16 code unit.

QJsonObject is implicitly shared: copies are cheap and the data is copied when one of them is modified. It is reentrant, but one object must not be modified while another thread reads it or a copy that shares its data.

Inserting or removing a key invalidates the iterators, because the entries after it move; so does anything else that changes the number of keys. Assigning through an iterator, or through the QJsonValueRef that the operator[] functions return, changes a value in place and does not.

See also QJsonValue, QJsonArray and QJsonDocument.

Differences from Qt

The iterators hold the object and an index instead of a pointer, so a copy made while one is alive is harmless: writes through a non-const iterator go to the object it came from. Assigning an undefined value through operator[] or an iterator stores it, and it is written as null; only insert() removes the key.
