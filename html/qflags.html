Detailed Description

Combining plain enum values produces an int, which loses the type and accepts values from any enum. QFlags<Enum> keeps the type, so a function taking QFlags<Enum> rejects unrelated values at compile time.

Declare the flags type next to the enum, then enable the | operator for bare enum values at namespace scope:

class Door {
public:
    enum Option { Locked = 0x1, Alarmed = 0x2 };
    Q_DECLARE_FLAGS(Options, Option)
};
Q_DECLARE_OPERATORS_FOR_FLAGS(Door::Options)

A value-less flag, such as an enumerator equal to 0, can only be detected with testFlag() when no other flag is set.

Differences from Qt

The stored value is always an int; there is no toInt() or fromInt() in the public API.
