Detailed Description

A QSpan holds a pointer and an element count. It does not own or copy the elements, so the sequence it refers to must outlive the span. Spans are cheap to copy and are normally passed by value. A QSpan<const T> gives read-only access, and a QSpan<T> lets the elements be modified.

A QSpan can be constructed from a pointer and a count, a pair of pointers, a C array, a std::array, or any container providing data() and size() such as QList or std::vector:

QList<int> values = {1, 2, 3, 4};
QSpan<const int> view(values);
int sum = 0;
for (int v : view.first(2))
    sum += v;

Differences from Qt

The extent is not enforced: every QSpan stores its size at run time, and first(), last() and the other slicing functions always return a dynamic-extent QSpan<T>. Indexes and counts are not bounds-checked. There are no crbegin() or crend() functions, and no conversion to a byte span.
