Detailed Description

QAtomicInteger<T> wraps a std::atomic<T> and offers the Qt-style load, store, compare-and-swap and fetch-and-modify operations. Functions with Ordered in their name use sequentially consistent ordering; those with Relaxed, Acquire or Release use the corresponding memory order. Plain load(), store(), the conversion operator and the arithmetic operators are sequentially consistent.

QAtomicInt is the common instantiation for int, and is typically used as a thread-safe reference count:

QAtomicInt refCount(1);

void retain() { refCount.ref(); }
void release() { if (!refCount.deref()) delete this; }

See also QAtomicPointer.

Differences from Qt

Only the Ordered variants of most operations are provided. There are no fetchAndStoreRelaxed(), fetchAndStoreAcquire(), fetchAndStoreRelease(), testAndSetAcquire(), testAndSetRelease(), fetchAndSubRelaxed() or similar relaxed/acquire/release forms beyond those documented here, no testAndSet overloads that report the current value, and no is...Native() queries other than isReferenceCountingNative().

Member Function Documentation

[constexpr] QAtomicInteger::QAtomicInteger(T v = 0)

Constructs an atomic integer holding v.

QAtomicInteger::QAtomicInteger(const QAtomicInteger &o)

Constructs a copy of o. The value is read with relaxed ordering; the copy is not atomic with respect to other threads.

bool QAtomicInteger::deref()

Atomically decrements the value by one. Returns true if the new value is not zero; otherwise returns false.

See also ref().

T QAtomicInteger::fetchAndAddOrdered(T v)

Atomically adds v to the value and returns the previous value.

See also fetchAndAddRelaxed() and fetchAndSubOrdered().

T QAtomicInteger::fetchAndAddRelaxed(T v)

Atomically adds v to the value with relaxed ordering and returns the previous value.

See also fetchAndAddOrdered().

T QAtomicInteger::fetchAndAndOrdered(T v)

Atomically performs a bitwise AND of the value with v and returns the previous value.

T QAtomicInteger::fetchAndOrOrdered(T v)

Atomically performs a bitwise OR of the value with v and returns the previous value.

T QAtomicInteger::fetchAndStoreOrdered(T v)

Atomically replaces the value with v and returns the previous value.

T QAtomicInteger::fetchAndSubOrdered(T v)

Atomically subtracts v from the value and returns the previous value.

See also fetchAndAddOrdered().

T QAtomicInteger::fetchAndXorOrdered(T v)

Atomically performs a bitwise XOR of the value with v and returns the previous value.

[static, constexpr] bool QAtomicInteger::isReferenceCountingNative()

Returns true; reference counting with ref() and deref() is always natively supported.

T QAtomicInteger::load() const

T QAtomicInteger::loadAcquire() const

Atomically loads and returns the value with acquire memory ordering.

T QAtomicInteger::loadRelaxed() const

Atomically loads and returns the value with relaxed memory ordering.

See also loadAcquire() and load().

QAtomicInteger::operator T() const

bool QAtomicInteger::testAndSetOrdered(T expected, T desired)

Atomically compares the value with expected and, if they are equal, replaces it with desired, using sequentially consistent ordering. Returns true if the value was replaced; otherwise returns false.
