Detailed Description

QTemporaryFile creates a uniquely named file that is safe to use from several processes. The file is created by open() and, by default, removed when the object is destroyed.

The file name is built from a template. The six characters XXXXXX in the last path component are replaced by random characters. A template without XXXXXX gets .XXXXXX appended. The default template is qt_temp.XXXXXX in QDir::tempPath(); a relative template is resolved against the current directory.

QTemporaryFile file;
if (file.open()) {
    file.write("scratch data");
    const QString name = file.fileName();
}

See also QTemporaryDir, QFile and QSaveFile.

Differences from Qt

open() always opens the file for reading and writing, whatever mode was requested; only the Append, Truncate, Text and Unbuffered flags are honored. There are no createNativeFile() and rename() functions.

Member Function Documentation

QTemporaryFile::QTemporaryFile()

Constructs a QTemporaryFile using the default template, which is qt_temp.XXXXXX in QDir::tempPath(). The file is created by open().

See also setFileTemplate().

[explicit] QTemporaryFile::QTemporaryFile(const QString &templateName)

Constructs a QTemporaryFile with the given templateName. The file is created by open().

See also setFileTemplate().

[explicit] QTemporaryFile::QTemporaryFile(QObject *parent)

Constructs a QTemporaryFile with the given parent, using the default template.

QTemporaryFile::QTemporaryFile(const QString &templateName, QObject *parent)

Constructs a QTemporaryFile with the given parent, using templateName as the file name template.

[override] QTemporaryFile::~QTemporaryFile()

Destroys the temporary file object, closing the file. The file is deleted if autoRemove() is true.

See also autoRemove().

bool QTemporaryFile::autoRemove() const

Returns true if the temporary file is removed when the object is destroyed; otherwise returns false. The default is true.

See also setAutoRemove().

QString QTemporaryFile::fileName() const

Returns the name of the temporary file, or an empty string if it has not been created yet.

See also QFileDevice::fileName().

QString QTemporaryFile::fileTemplate() const

Returns the file name template, which is qt_temp.XXXXXX in QDir::tempPath() by default.

See also setFileTemplate().

bool QTemporaryFile::open()

This is an overloaded function.

Creates the file from the template and opens it for reading and writing. Returns true on success; otherwise returns false.

[override, protected] bool QTemporaryFile::open(OpenMode mode)

Reimplements QFile::open().

Creates the file from the template and opens it for reading and writing. Only the Append, Truncate, Text and Unbuffered flags of mode are used. Returns true on success; otherwise returns false and sets error() to OpenError. If the file was already created by an earlier call, it is reopened under the same name.

See also open().

void QTemporaryFile::setAutoRemove(bool b)

Sets whether the file is removed when the object is destroyed to b.

See also autoRemove().

void QTemporaryFile::setFileTemplate(const QString &name)

Sets the file name template to name. If the file is already created, the template has no effect.

See also fileTemplate().
