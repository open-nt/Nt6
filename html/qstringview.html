Detailed Description

A QStringView refers to a contiguous range of QChars without owning or copying it, so the viewed data must outlive the view. It is cheap to copy and is meant for function parameters that only read text, accepting a QString, a u"" literal or a std::u16string_view alike.

A view is null if it was constructed without data (or from a null QString), and empty if its size is 0. A null view is also empty.

See also QString, QStringList and QLatin1StringView.

Differences from Qt

Only part of the Qt API is provided: construction, element access, slicing, trimmed(), startsWith(), endsWith(), indexOf(), lastIndexOf(), contains(), compare(), a few number conversions (toInt(), toUInt(), toLongLong(), toULongLong() and toDouble()) and the comparison operators. The searching, comparison and conversion functions copy the view into a QString first, so they allocate. split(), count(), toLocal8Bit(), toUcs4(), the other toXxx() number conversions, the reverse iterators, isRightToLeft(), the QLatin1StringView overloads and the QRegularExpression overloads are not provided. first(), last(), sliced(), chopped(), truncate() and chop() do not check their arguments.
