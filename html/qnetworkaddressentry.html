int QNetworkAddressEntry::prefixLength() const

Returns the number of leading one bits in the netmask, or -1 if the netmask is unset.

See also setPrefixLength().

void QNetworkAddressEntry::setPrefixLength(int length)

Sets the netmask from a prefix of length bits. The IP address must be set first, as it decides between an IPv4 and an IPv6 mask.

See also prefixLength() and setIp().
