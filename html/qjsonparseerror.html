Detailed Description

QJsonDocument::fromJson() fills one in when it is given a pointer to it. error is NoError on success; otherwise offset is the byte offset in the input at which the parser noticed the problem.

QJsonParseError err;
QJsonDocument doc = QJsonDocument::fromJson(text, &err);
if (err.error != QJsonParseError::NoError)
    qWarning() << err.errorString() << "at" << err.offset;

See also QJsonDocument::fromJson().

Differences from Qt

The members start out as 0 and NoError instead of being uninitialized. The text of errorString() is not translated.
