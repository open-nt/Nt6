Detailed Description

A QChar holds one UTF-16 code unit. Characters outside the Basic Multilingual Plane are represented by a pair of QChar surrogates; see isHighSurrogate() and isLowSurrogate(). QChar is the element type of QString.

The classification functions (isLetter(), isSpace(), isUpper() and so on) and the case conversions (toLower(), toUpper()) are implemented with built-in tables rather than the full Unicode database.

See also QString and QLatin1Char.

Differences from Qt

Classification and case mapping cover ASCII, Latin-1, Latin Extended-A, Greek and Cyrillic only (isLetter() also recognizes the Japanese kana, CJK ideographs and Hangul syllables); characters from other scripts are returned unchanged. isNumber() and digitValue() recognize only the ASCII digits, and toCaseFolded() is the same as toLower(). The surrogate-pair helpers (requiresSurrogates(), fromUcs4(), toUcs4()), the category(), script() and decomposition() functions, isMark(), isSymbol() and the Category, Script and Direction enums are not provided. QChar has no char32_t constructor.

bool QChar::isDigit() const

Returns true if this is an ASCII digit (0 to 9); otherwise returns false. Digits from other scripts are not recognized.

See also isNumber() and digitValue().

bool QChar::isHighSurrogate() const

Returns true if this is a UTF-16 high surrogate (U+D800 to U+DBFF); otherwise returns false.

See also isLowSurrogate() and isSurrogate().

bool QChar::isLetter() const

Returns true if this is a letter; otherwise returns false.

Classification covers ASCII, Latin-1, Latin Extended, Greek, Cyrillic, Hiragana, Katakana, CJK ideographs and Hangul syllables. Letters from other scripts are not recognized.

See also isLetterOrNumber(), isUpper() and isLower().

bool QChar::isLetterOrNumber() const

Returns true if this is a letter or a number; otherwise returns false.

See also isLetter() and isNumber().

bool QChar::isLower() const

Returns true if this is a lowercase letter, that is a letter whose toUpper() is a different character; otherwise returns false.

See also isUpper() and toLower().

bool QChar::isLowSurrogate() const

Returns true if this is a UTF-16 low surrogate (U+DC00 to U+DFFF); otherwise returns false.

See also isHighSurrogate() and isSurrogate().

[constexpr] bool QChar::isNull() const

Returns true if this is the null character (U+0000); otherwise returns false.

bool QChar::isNumber() const

Returns true if this is a number. Only the ASCII digits count as numbers, so this is the same as isDigit().

See also isDigit() and isLetterOrNumber().

bool QChar::isPrint() const

Returns true if this is a printable character, that is, not a C0 or C1 control character and not U+007F; otherwise returns false.

bool QChar::isPunct() const

Returns true if this is a punctuation character; otherwise returns false.

Classification covers ASCII, a few Latin-1 characters and the General Punctuation block (U+2010 to U+205E).

bool QChar::isSpace() const

Returns true if this is a white space character, including the control characters U+0009 to U+000D, U+0085, the no-break space and the Unicode space separators; otherwise returns false.

bool QChar::isSurrogate() const

Returns true if this is a UTF-16 surrogate (U+D800 to U+DFFF); otherwise returns false.

See also isHighSurrogate() and isLowSurrogate().

bool QChar::isUpper() const

Returns true if this is an uppercase letter, that is a letter whose toLower() is a different character; otherwise returns false.

See also isLower() and toUpper().

[constexpr] uchar QChar::row() const

Returns the high byte of the code unit (the "row" of its plane).

See also cell() and unicode().

QChar QChar::toCaseFolded() const

Returns the case folded equivalent of this character. This is the same as toLower().

See also toLower().

[constexpr] char QChar::toLatin1() const

Returns the Latin-1 representation of this character, or '\\0' if it is outside the range 0 to 255.

See also fromLatin1() and unicode().

QChar QChar::toLower() const

Returns the lowercase equivalent of this character, or the character itself if it has none.

Case mapping covers ASCII, Latin-1, Latin Extended-A, Greek and Cyrillic only.

See also toUpper() and toCaseFolded().

QChar QChar::toUpper() const

Returns the uppercase equivalent of this character, or the character itself if it has none.

Case mapping covers ASCII, Latin-1, Latin Extended-A, Greek and Cyrillic only.

See also toLower().

[constexpr] char16_t QChar::unicode() const

Returns the UTF-16 code unit of this character.

See also cell() and row().

[constexpr] char16_t & QChar::unicode()

This is an overloaded function.

Returns a reference to the UTF-16 code unit of this character, which can be used to modify it.
