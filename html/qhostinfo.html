Detailed Description

Call lookupHost() to resolve a name without blocking the event loop. The function you pass receives the result:

QHostInfo::lookupHost("example.com", [](const QHostInfo &info) {
    if (info.error() == QHostInfo::NoError)
        qDebug() << info.addresses().first().toString();
});

fromName() does the same lookup and blocks until it finishes.

See also QHostAddress.

Differences from Qt

There is no string-based SLOT() overload of lookupHost(). Each lookup uses its own thread rather than a shared pool, and abortHostLookup() only discards the result: the system resolver call itself runs to completion.
