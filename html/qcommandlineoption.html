Detailed Description

An option has one or more names, a description for the help text and optionally a value. Add options to a QCommandLineParser, then query the parser after parsing:

QCommandLineParser parser;
QCommandLineOption output({"o", "output"}, "Write to <file>.", "file");
parser.addOption(output);
parser.process(QCoreApplication::arguments());
QString path = parser.value(output);

Names that are empty, start with - or contain = are not valid; they are dropped with a warning.

See also QCommandLineParser.

Differences from Qt

There is no swap() and no setHidden() or isHidden(); use the HiddenFromHelp flag instead.

enum QCommandLineOption::Flag

Flags that change how an option is shown in the help text.

ConstantDescription
QCommandLineOption::HiddenFromHelpThe option is left out of QCommandLineParser::helpText().
QCommandLineOption::ShortOptionStyleThe option's names are all shown with a single dash, even the long ones.

typedef QCommandLineOption::Flags

The Flags type is a typedef for QFlags<Flag>. It stores an OR combination of Flag values.

This is an overloaded function.

Constructs a command line option with the single name name, the help text description and, if valueName is not empty, a value with that name and the default defaultValue.

QCommandLineOption::QCommandLineOption(const QStringList &names, const QString &description, const QString &valueName = QString(), const QString &defaultValue = QString())

This is an overloaded function.

Constructs a command line option with the names names and the help text description. If valueName is not empty the option takes a value with that name, and defaultValue is used when it is not given. Names that are not valid are dropped.
