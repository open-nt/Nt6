Detailed Description

Events are delivered to QObject::event() by QCoreApplication::sendEvent() or QCoreApplication::postEvent(). A QEvent carries its type() and an accept flag, and subclasses add the data for a specific kind of event.

See also QObject::event(), QTimerEvent and QCoreApplication.

Differences from Qt

Only the event types in QEvent::Type exist. There is no clone(), spontaneous() or QEvent::isInputEvent(), and events cannot be copied.

Member Type Documentation

enum QEvent::Type

This enum describes the kinds of event Nt delivers.

ConstantDescription
QEvent::NoneNot an event.
QEvent::TimerA timer fired; delivered as a QTimerEvent.
QEvent::MetaCallA queued signal-slot invocation, handled by QObject::event().
QEvent::ThreadChangeThe object is about to move to another thread; see QObject::moveToThread().
QEvent::SockActA socket notifier became active; see QSocketNotifier.
QEvent::DynamicPropertyChangeA dynamic property was added, changed or removed; delivered as a QDynamicPropertyChangeEvent.
QEvent::DeferredDeleteThe receiver should be deleted; posted by QObject::deleteLater().
QEvent::UpdateRequestA request to update a deferred state; QSettings posts it to write its changes back from the event loop.
QEvent::UserThe first value available for application-defined events.
QEvent::MaxUserThe last value available for application-defined events.

void QEvent::accept()

Marks the event as accepted. This is the same as setAccepted(true).

See also ignore().

void QEvent::ignore()

Marks the event as ignored, so the receiver does not handle it. This is the same as setAccepted(false).

See also accept().

bool QEvent::isAccepted() const

Returns true if the event has been accepted; otherwise returns false. Events are accepted when constructed.

See also setAccepted(), accept() and ignore().

[static] int QEvent::registerEventType(int hint = -1)

Registers and returns a custom event type. If hint lies between QEvent::User and QEvent::MaxUser and has not been handed out before, it is returned. Otherwise an unused type is allocated, counting down from QEvent::MaxUser. Returns -1 if no type is available.

The function is thread-safe.

void QEvent::setAccepted(bool a)

Sets the accept flag to a.

See also isAccepted().
