Detailed Description

The default verifies peers against the system's trusted certificates and requires TLS 1.2 or newer. To trust a private CA alongside them:

QSslConfiguration config = QSslConfiguration::defaultConfiguration();
config.addCaCertificates(QSslCertificate::fromPath("company-ca.pem"));
socket.setSslConfiguration(config);

Use setCaCertificates() instead to trust only the certificates you list.

See also QSslSocket.

Differences from Qt

caCertificates() lists only certificates you added: system ones are used by OpenSSL directly and are not enumerated, so systemCaCertificates() does not exist. usesSystemCaCertificates() is an Nt addition. Cipher selection, session tickets, OCSP and DTLS settings are absent.
