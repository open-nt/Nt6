Detailed Description

Create one QCoreApplication in main() before using timers, posted events or queued connections, and call exec() to run the event loop:

int main(int argc, char *argv[])
{
    QCoreApplication app(argc, argv);
    QTimer::singleShot(100, [] { QCoreApplication::quit(); });
    return app.exec();
}

The class also holds the command line, the application name and version, and provides functions to send and post events.

See also QEventLoop, QObject and QCommandLineParser.

Differences from Qt

Only part of the Qt API is present: there is no installTranslator(), libraryPaths(), applicationFilePath(), processEvents() overload with a timeout or postEvent() priority. Creating a second application object aborts the process. exit() and quit() stop every running QEventLoop of the thread that created the application object, and aboutToQuit() is emitted after the main loop has stopped. Unlike Qt, they do not make later calls to exec() return at once. postEvent() may be called from any thread; processEvents() and sendPostedEvents() work on the calling thread's queue. qApp is defined as QCoreApplication::instance().

Member Function Documentation

QCoreApplication::QCoreApplication(int &argc, char **argv)

Constructs a core application from the command line given by argc and argv. Both must remain valid for the lifetime of the application, and only one application object may exist at a time; creating a second one prints a message and aborts the process.

See also arguments().

[override] QCoreApplication::~QCoreApplication()

Destroys the application object. After this, instance() returns nullptr.

[signal] void QCoreApplication::aboutToQuit()

This signal is emitted by exec() after the event loop has stopped, just before exec() returns. Use it to release resources.

See also quit().

[static] QString QCoreApplication::applicationName()

Returns the application name. Unless it was set with setApplicationName(), this is the file name part of the program path in the command line, or an empty string if there is no command line.

See also setApplicationName() and arguments().

[static] QString QCoreApplication::applicationVersion()

Returns the application version, which is empty unless it was set with setApplicationVersion().

See also setApplicationVersion().

[static] QStringList QCoreApplication::arguments()

Returns the command line as passed to the constructor, decoded as UTF-8. The first entry is the program name.

See also applicationName().

[static] int QCoreApplication::exec()

Enters the main event loop and waits until exit() or quit() is called, then emits aboutToQuit() and returns the code passed to exit().

See also quit(), exit() and QEventLoop::exec().

[static] void QCoreApplication::exit(int returnCode = 0)

Tells every running event loop to exit with the return code returnCode.

See also quit() and exec().

[static] QCoreApplication * QCoreApplication::instance()

Returns the application object, or nullptr if none exists.

[virtual] bool QCoreApplication::notify(QObject *receiver, QEvent *event)

Delivers event to receiver by calling QObject::event() and returns its result. Reimplement it to intercept every event sent to any object in the application.

See also sendEvent() and QObject::event().

[static] QString QCoreApplication::organizationDomain()

Returns the Internet domain of the organization, which is empty unless it was set with setOrganizationDomain().

See also setOrganizationDomain() and organizationName().

[static] QString QCoreApplication::organizationName()

Returns the name of the organization, which is empty unless it was set with setOrganizationName().

See also setOrganizationName() and organizationDomain().

[static] void QCoreApplication::postEvent(QObject *receiver, QEvent *event)

Adds event to the event queue of receiver and returns immediately. The event is delivered from the event loop. The queue takes ownership of event and deletes it after delivery; if receiver is nullptr the event is deleted at once.

See also sendEvent() and removePostedEvents().

[static] void QCoreApplication::processEvents(QEventLoop::ProcessEventsFlags flags = QEventLoop::AllEvents)

Processes pending events once according to flags. With QEventLoop::WaitForMoreEvents the call blocks until an event is available. Other flags are ignored.

See also QEventLoop::processEvents().

[slot, static] void QCoreApplication::quit()

Tells the application to exit with return code 0. This is the same as calling exit(0).

See also exit() and aboutToQuit().

[static] void QCoreApplication::removePostedEvents(QObject *receiver, int eventType = 0)

Removes the posted events for receiver that have not been delivered yet. If eventType is 0, every pending event is removed; otherwise only events of that type.

See also postEvent().

[static] bool QCoreApplication::sendEvent(QObject *receiver, QEvent *event)

Sends event directly to receiver through notify() and returns the value the event handler returned. The caller keeps ownership of event. Returns false if receiver or event is nullptr.

See also postEvent() and notify().

[static] void QCoreApplication::sendPostedEvents(QObject *receiver = nullptr, int eventType = 0)

Delivers the events posted to receiver that match eventType right away, in the calling thread, and removes them from the queue. If receiver is nullptr, the events of every object that lives in the calling thread match. An eventType of 0 matches all events except QEvent::DeferredDelete, which is delivered only when asked for by type or by an event loop. receiver must live in the calling thread.

See also postEvent() and processEvents().

[static] void QCoreApplication::setApplicationName(const QString &name)

Sets the application name to name.

See also applicationName().

[static] void QCoreApplication::setApplicationVersion(const QString &version)

Sets the application version to version.

See also applicationVersion() and QCommandLineParser::addVersionOption().

[static] void QCoreApplication::setOrganizationDomain(const QString &orgDomain)

Sets the Internet domain of the organization to orgDomain.

See also organizationDomain() and setOrganizationName().

[static] void QCoreApplication::setOrganizationName(const QString &orgName)

Sets the name of the organization to orgName. QSettings uses it to locate the settings of the application.
