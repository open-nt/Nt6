Detailed Description

QString stores a string of 16-bit QChars (UTF-16 code units). It is the string type used throughout Nt. Strings are created from UTF-8 literals, Latin-1 data or UTF-16 data, and converted back with toUtf8(), toLatin1() and toStdString():

QString s = QStringLiteral("Hello, %1!").arg("world");
if (s.startsWith("Hello"))
    qDebug() << s.toUpper();

A QString can be null (the result of the default constructor, see isNull()) or empty (no characters); a null string is also empty, and the two are interchangeable in comparisons.

Unlike in Qt the string data is not implicitly shared: every copy of a QString copies the characters.

See also QChar, QStringList, QStringView and QByteArray.

Differences from Qt

The string is a thin wrapper around std::u16string and copies on assignment; there is no implicit sharing, so fromRawData() copies its argument. Case conversion, case-insensitive comparison and QChar classification cover ASCII, Latin-1, Latin Extended-A, Greek and Cyrillic only. There is no locale support: localeAwareCompare() is a plain comparison, toLocal8Bit() and fromLocal8Bit() use UTF-8, and a %L1 place marker in arg() is handled like %1. count() returns 0 for an empty argument. Functions taking QStringView or QLatin1StringView are mostly missing; use the QString overloads. Not provided are the QRegularExpression overloads, normalized(), toHtmlEscaped(), toWCharArray(), fromWCharArray(), toUcs4(), fromUcs4(), setRawData(), setUnicode() and setUtf16(), nor QStringBuilder concatenation.

QString QString::arg(const QString &a, int fieldWidth = 0, QChar fillChar = QChar(u' ')) const

Returns a copy of this string in which the lowest-numbered place marker (%1 to %99, optionally written %L1) is replaced by a.

a is padded to at least fieldWidth characters with fillChar; a positive fieldWidth right-aligns it and a negative one left-aligns it (padding with spaces). If the string contains no place marker, a space and a are appended.

QString s = QString("%1 of %2").arg("1").arg("3"); // "1 of 3"

See also number().

int QString::compare(const QString &o, Qt::CaseSensitivity cs = Qt::CaseSensitive) const

Compares this string with o, using the case sensitivity cs, and returns a negative integer, zero or a positive integer if this string is less than, equal to or greater than o. [static] QString QString::number(double n, char format = 'g', int precision = 6)

This is an overloaded function.

Returns a string holding the representation of the floating-point value n. format is one of 'f' (fixed), 'e' (scientific) or 'g' (the shorter of the two), with an uppercase letter selecting an uppercase exponent; any other value is treated as 'g'. precision is the number of digits after the decimal point for 'f' and 'e', or the number of significant digits for 'g'. If precision is negative, the shortest representation that round-trips is produced. The C locale is always used.

See also toDouble() and setNum().

qlonglong QString::toLongLong(bool *ok = nullptr, int base = 10) const

Returns the string converted to a long long using base, which must be between 2 and 36 or 0. If base is 0, the C prefixes 0x and 0 select hexadecimal and octal, and decimal is used otherwise. If ok is not nullptr, it is set to true on success and false on failure (for example when the string is empty, has other trailing characters, contains non-ASCII characters or the value overflows), in which case 0 is returned. See also number(), toULongLong() and toInt().
