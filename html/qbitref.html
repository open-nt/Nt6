Detailed Description

A QBitRef is returned by the non-const operator[]() of QBitArray. It refers to one bit of the array, so that the bit can be both read and assigned with the subscript operator.

QBitArray bits(8);
bits[3] = true;

See also QBitArray.

Differences from Qt

The class is the same as in Qt, but it holds a reference to the array and is invalidated if the array is destroyed.
