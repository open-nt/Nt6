Detailed Description

availablePorts() lists the ports of the machine. Each entry gives the name of the port, which can be passed to QSerialPort, and what is known about the hardware behind it:

const QList<QSerialPortInfo> ports = QSerialPortInfo::availablePorts();
for (const QSerialPortInfo &info : ports) {
    qDebug() << info.portName() << info.description();
    if (info.hasVendorIdentifier())
        qDebug() << "USB vendor" << info.vendorIdentifier();
}

See also QSerialPort.

Differences from Qt

Ports are found through sysfs, so availablePorts() returns nothing on other systems, and only USB and PCI hardware reports identifiers. Pseudo terminals are not listed, because they have no entry in sysfs. Objects of this class are plain values, not implicitly shared.
