Detailed Description

A QDateTime combines a QDate and a QTime with a time specification: local time, UTC, or a fixed offset from UTC. It converts to and from milliseconds since the Unix epoch, 1970-01-01T00:00:00 UTC.

QDateTime now = QDateTime::currentDateTimeUtc();
QDateTime later = now.addDays(7);
later.toString(Qt::ISODate); // "2026-11-14T10:10:14Z"

See also QDate and QTime.

Differences from Qt

There is no QTimeZone support. Qt::TimeZone is not a supported specification, so only local time, UTC and fixed offsets can be used, and local time follows the system's current rules through mktime(). There are no timeZone(), setTimeZone(), toTimeZone(), isDaylightTime(), timeZoneAbbreviation(), swap() or fromTime_t() functions, and no currentDateTime() overload that takes a time zone. Text formats use English text and the format string accepts the QDate and QTime expressions plus t for the time zone.

Member Function Documentation

QDateTime::QDateTime()

Constructs a null datetime, which is invalid.

See also isNull() and isValid().

QDateTime::QDateTime(QDate date, QTime time, Qt::TimeSpec spec = Qt::LocalTime, int offsetSeconds = 0)

Constructs a datetime from date and time, interpreted according to spec. For Qt::OffsetFromUTC, offsetSeconds is the offset from UTC in seconds; an offset of 0 makes the datetime UTC. If date is valid and time is null, the time is taken as midnight.

See also isValid().

QDateTime QDateTime::addDays(qint64 days) const

Returns a QDateTime that is days days after this one, or before it if days is negative. The time and time specification are kept; the date changes as QDate::addDays() does.

See also addMonths(), addYears(), addSecs() and daysTo().

QDateTime QDateTime::addMonths(int months) const

Returns a QDateTime that is months months after this one, or before it if months is negative. The day is clamped as QDate::addMonths() does.

See also addDays() and addYears().

QDateTime QDateTime::addMSecs(qint64 msecs) const

Returns a QDateTime that is msecs milliseconds after this one, or before it if msecs is negative, in the same time specification. Returns an invalid QDateTime if this one is invalid.

See also addSecs() and msecsTo().

QDateTime QDateTime::addSecs(qint64 secs) const

Returns a QDateTime that is secs seconds after this one, or before it if secs is negative.

See also addMSecs() and secsTo().

QDateTime QDateTime::addYears(int years) const

Returns a QDateTime that is years years after this one, or before it if years is negative. The day is clamped as QDate::addYears() does.

See also addDays() and addMonths().

[static] QDateTime QDateTime::fromString(const QString &string, Qt::DateFormat format = Qt::TextDate)

Parses string in the given format and returns the datetime. Returns an invalid QDateTime if string does not match. ISO 8601 text may use a space instead of T, omit the time (which then means midnight), and end with Z or an offset; without either it is local time. RFC2822Date accepts an optional leading weekday, optional seconds, and a zone of GMT, UT, UTC, Z or +hhmm. TextDate expects ddd MMM d HH:mm:ss yyyy, optionally followed by GMT and an offset.

See also toString().

[static] QDateTime QDateTime::fromString(const QString &string, const QString &format)

This is an overloaded function.

Parses string using format, which uses the expressions of QDate and QTime, and returns the datetime in local time. Returns an invalid QDateTime if string does not match format.

See also toString().

bool QDateTime::isNull() const

Returns true if both the date and the time are null; otherwise returns false.

See also isValid().

bool QDateTime::isValid() const

Returns true if both the date and the time are valid; otherwise returns false.

See also isNull().

qint64 QDateTime::msecsTo(const QDateTime &o) const

Returns the number of milliseconds from this datetime to o, which is negative if o is earlier. The difference is taken between the instants the two datetimes represent, so their time specifications do not matter.

See also secsTo() and addMSecs().

int QDateTime::offsetFromUtc() const

Returns the datetime's offset from UTC in seconds. It is 0 for UTC, the stored offset for Qt::OffsetFromUTC, and the system's offset at that moment for local time. Returns 0 for an invalid local datetime.

See also setOffsetFromUtc() and timeSpec().

qint64 QDateTime::secsTo(const QDateTime &o) const

Returns the number of whole seconds from this datetime to o, which is negative if o is earlier. The difference is taken between the instants the two datetimes represent, so their time specifications do not matter.

See also msecsTo() and addSecs().

void QDateTime::setDate(QDate date)

QString QDateTime::toString(Qt::DateFormat format = Qt::TextDate) const

Returns the datetime as text in the given format, or an empty string if the datetime is invalid. ISODate and ISODateWithMs give yyyy-MM-ddTHH:mm:ss, with milliseconds for ISODateWithMs, followed by Z for UTC or the offset such as +10:00. The result is empty for years outside 0 to 9999. RFC2822Date gives dd MMM yyyy hh:mm:ss +hhmm. TextDate gives ddd MMM d HH:mm:ss yyyy, followed by GMT and the offset for UTC and offset datetimes.

See also fromString().

QString QDateTime::toString(const QString &format) const

This is an overloaded function.

Returns the datetime as text using format, or an empty string if the datetime is invalid. It accepts the expressions of QDate and QTime, plus t, which gives UTC or UTC followed by the offset, such as UTC+10:00.

See also fromString().

QDateTime QDateTime::toTimeSpec(Qt::TimeSpec spec) const

Returns a copy of this datetime converted to the time specification spec, representing the same instant. Converting to Qt::OffsetFromUTC keeps the current offset.

See also toLocalTime(), toUTC() and toOffsetFromUtc().

QDateTime QDateTime::toUTC() const

Returns a copy of this datetime converted to UTC.

See also toLocalTime() and toTimeSpec().
