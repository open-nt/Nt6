Detailed Description

QSharedPointer<T> shares ownership of an object through atomic reference counting. The object is deleted when the last QSharedPointer referring to it is destroyed or reset. QSharedPointer inherits from std::shared_ptr<T>, so the standard interface (get(), reset(), use_count(), operator*() and so on) is also available.

See also QWeakPointer and QEnableSharedFromThis.

Differences from Qt

QSharedPointer is a thin subclass of std::shared_ptr<T>, so reference counting and the deleter follow the standard library. There is no objectCast(), qSharedPointerObjectCast(), qSharedPointerConstCast() or qHash(), and no custom-deleter reset() overload.

[explicit] QSharedPointer::QSharedPointer(T *p)

Constructs a shared pointer that takes ownership of p, which is deleted with delete when the last reference goes away.

QSharedPointer::QSharedPointer(const Base &b)

This is an overloaded function.

Constructs a shared pointer from the std::shared_ptr b, sharing its ownership.

This is an overloaded function.

Constructs a shared pointer from o, whose pointer type X * must be implicitly convertible to T *.

QSharedPointer::QSharedPointer(const QWeakPointer<T> &w)

Constructs a shared pointer from the weak pointer w. The result is null if the object w referred to has already been destroyed.

See also QWeakPointer::toStrongRef().

void QSharedPointer::clear()

Releases this reference and makes the pointer null.

template <typename X>QSharedPointer<X> QSharedPointer::constCast() const

T * QSharedPointer::data() const

template <typename X>QSharedPointer<X> QSharedPointer::dynamicCast() const

Returns a shared pointer to the same object converted to X * with dynamic_cast. The result is null if the cast fails.

bool QSharedPointer::isNull() const

Returns true if this pointer is null; otherwise returns false.

template <typename X>QSharedPointer<X> QSharedPointer::staticCast() const

Returns a shared pointer to the same object converted to X * with static_cast. The reference count is shared with this pointer.

QWeakPointer<T> QSharedPointer::toWeakRef() const

Returns a QWeakPointer that observes the same object without keeping it alive.
