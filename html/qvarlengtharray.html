Detailed Description

QVarLengthArray<T, Prealloc> is a resizable array that stores its first Prealloc items inside the object itself and switches to heap memory only when it grows beyond that. For short-lived, small arrays, such as temporary buffers in a function, this avoids a heap allocation.

QVarLengthArray<int, 16> values;
for (int i = 0; i < 10; ++i)
    values.append(i * i);

See also QList.

Differences from Qt

There is no first(n), last(n), mid(), sliced(), removeAll(), removeOne(), removeIf(), takeAt(), startsWith(), endsWith(), max_size() or assign(), no rvalue overload of insert(), and the only comparison operators are operator==() and operator!=(). Indexes are not range-checked except by value().
