Detailed Description

QFile file("server.key");
file.open(QIODevice::ReadOnly);
QSslKey key(file.readAll(), QSsl::Ec);

See also QSslCertificate and QSslConfiguration.

Differences from Qt

toPem() and toDer() have no pass phrase argument, and the key is held unencrypted in memory after it is loaded. There is no handle().

Member Function Documentation

QSslKey::QSslKey()

Constructs a null key.

QSslKey::QSslKey(const QByteArray &encoded, QSsl::KeyAlgorithm algorithm, QSsl::EncodingFormat format = QSsl::Pem, QSsl::KeyType type = QSsl::PrivateKey, const QByteArray &passPhrase = QByteArray())

Constructs a key by parsing encoded, which is in format and holds a key of the given type. passPhrase decrypts a protected key. The key is null if parsing fails, or if the key is not an algorithm key.

See also isNull().
