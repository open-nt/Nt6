Detailed Description

A QWaitCondition lets a thread sleep until another thread signals that something has changed. The waiting thread passes a locked QMutex to wait(); the mutex is released while the thread sleeps and locked again before wait() returns.

QMutex mutex;
QWaitCondition ready;
bool done = false;

void consumer()
{
    QMutexLocker locker(&mutex);
    while (!done)
        ready.wait(&mutex);
}

void producer()
{
    {
        QMutexLocker locker(&mutex);
        done = true;
    }
    ready.wakeAll();
}

See also QMutex and QSemaphore.

Differences from Qt

wait() accepts only a QMutex; there is no overload for QReadWriteLock. The notify_one() and notify_all() members, named as in the C++ standard library, are additions.

bool QWaitCondition::wait(QMutex *mutex, unsigned long timeMs = ULONG_MAX)

Releases mutex and waits on the condition for up to timeMs milliseconds. The mutex must be locked by the calling thread, and it is locked again before this function returns.

Returns true if the thread was woken by wakeOne() or wakeAll(), or false if the time elapsed. The default timeMs, ULONG_MAX, waits indefinitely.

See also wakeOne() and wakeAll().

bool QWaitCondition::wait(QMutex *mutex, QDeadlineTimer deadline)

This is an overloaded function.

Releases mutex and waits until woken or until deadline expires. A deadline that never expires waits indefinitely.

void QWaitCondition::wakeAll()

Wakes all threads waiting on the condition.

See also wakeOne() and wait().

void QWaitCondition::wakeOne()

Wakes one thread waiting on the condition. Which thread is woken is unspecified.

See also wakeAll() and wait().
