Nt Core C++ Classes

Core non-graphical classes: objects, signals, events, strings and containers.

Using the Module

target_link_libraries(app PRIVATE Nt::Core)

Nt Core provides the classes every Nt program builds on. Headers keep Qt's names, so #include <QObject> and #include <QtCore/QTimer> both work.

See Signals and Slots for how objects communicate.
