Detailed Description

A UUID is a 128-bit value, usually written as 32 hexadecimal digits in the form {xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx}. createUuid() returns a random (version 4) UUID, and createUuidV3() and createUuidV5() derive one from a namespace and a name.

QUuid id = QUuid::createUuid();
QString text = id.toString(QUuid::WithoutBraces);

See also QRandomGenerator and QCryptographicHash.

Differences from Qt

There is no createUuidV7(), no QUuid(QAnyStringView) or fromString(QAnyStringView), and no QDataStream, QDebug or Windows GUID conversions. Strings are parsed from a QStringView, a const char * or a QByteArray. There are no predefined namespace constants.

Member Type Documentation

enum QUuid::StringFormat

Selects the text format used by toString() and toByteArray().

ConstantDescription
QUuid::WithBracesThe canonical form with dashes, enclosed in braces: {xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx}.
QUuid::WithoutBracesThe canonical form with dashes but without braces.
QUuid::Id128The 32 hexadecimal digits with neither dashes nor braces.

enum QUuid::Variant

Describes the layout of a UUID, which is stored in the top bits of data4[0].

ConstantDescription
QUuid::VarUnknownThe variant is unknown. A null UUID has this variant.
QUuid::NCSReserved for NCS (Network Computing System) backward compatibility.
QUuid::DCEDistributed Computing Environment, the variant defined by RFC 4122.
QUuid::MicrosoftReserved for Microsoft Corporation backward compatibility.
QUuid::ReservedReserved for future definition.

See also variant().

enum QUuid::Version

Describes how a UUID of the DCE variant was generated.

ConstantDescription
QUuid::VerUnknownThe version is unknown, or the UUID is not of the DCE variant.
QUuid::TimeTime-based.
QUuid::EmbeddedPOSIXDCE security with embedded POSIX UIDs.
QUuid::Md5Name-based, hashed with MD5.
QUuid::NameThe same as Md5.
QUuid::RandomRandom-number based.
QUuid::Sha1Name-based, hashed with SHA-1.

See also version().

[static] QUuid QUuid::createUuid()

Creates a random (version 4, DCE variant) UUID using QRandomGenerator::system().

See also createUuidV3() and createUuidV5().

[static] QUuid QUuid::createUuidV3(const QUuid &ns, const QByteArray &name)

Creates a name-based, version 3 UUID by hashing name within the namespace ns with MD5. The same inputs always give the same UUID.

See also createUuidV5() and createUuid().

[static] QUuid QUuid::createUuidV3(const QUuid &ns, const QString &name)

This is an overloaded function.

Creates a version 3 UUID from name, converted to UTF-8, within the namespace ns.

[static] QUuid QUuid::createUuidV5(const QUuid &ns, const QByteArray &name)

Creates a name-based, version 5 UUID by hashing name within the namespace ns with SHA-1. The same inputs always give the same UUID.

See also createUuidV3() and createUuid().

[static] QUuid QUuid::createUuidV5(const QUuid &ns, const QString &name)

This is an overloaded function.

Creates a version 5 UUID from name, converted to UTF-8, within the namespace ns.

[static] QUuid QUuid::fromRfc4122(const QByteArray &bytes)

Creates a UUID from the 16 bytes in bytes, in network (big-endian) order. Returns a null UUID if bytes does not hold exactly 16 bytes.

See also toRfc4122().

[static] QUuid QUuid::fromString(QStringView text)

Parses text as a UUID. It must be 32 hexadecimal digits, or the canonical dashed form, optionally enclosed in braces. Digits may be upper or lower case. Returns a null UUID if text is not valid.

See also toString().

[static] QUuid QUuid::fromString(const char *text)

This is an overloaded function.

Parses the UTF-8 string text. Returns a null UUID if text is nullptr or not valid.

[static] QUuid QUuid::fromString(const QByteArray &text)

This is an overloaded function.

Parses the UTF-8 string text. Returns a null UUID if text is not valid.

bool QUuid::isNull() const

Returns true if all fields are zero; otherwise returns false.

QByteArray QUuid::toByteArray(StringFormat mode = WithBraces) const

Returns the UUID as lowercase hexadecimal text, as a QByteArray, in the given mode.

QByteArray QUuid::toRfc4122() const

Returns the UUID as 16 bytes in network (big-endian) order, as defined by RFC 4122.

See also fromRfc4122().

QString QUuid::toString(StringFormat mode = WithBraces) const

Returns the UUID as lowercase hexadecimal text in the given mode.

See also toByteArray() and fromString().

Variant QUuid::variant() const

Returns the variant of the UUID, or VarUnknown if it is null.

See also version().

Version QUuid::version() const

Returns the version of the UUID, or VerUnknown if it is not of the DCE variant or has an unrecognized version.

See also variant().
