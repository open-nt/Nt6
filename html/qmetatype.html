Detailed Description

QMetaType describes a C++ type at run time: its name, size, how to construct, copy, compare and destroy a value, and how to stream it. QVariant, queued connections and the property system are built on it.

Obtain one for a type with fromType(), or from an id or a name:

QMetaType t = QMetaType::fromType<QString>();
void *s = t.create();      // a new, empty QString
t.destroy(s);

QMetaType u = QMetaType::fromName("QString");
Q_ASSERT(t == u && t.id() == QMetaType::QString);

The built-in types have the same ids as in Qt. Any other type gets an id the first time it is registered, with qRegisterMetaType(), Q_DECLARE_METATYPE() or by asking for its id(); ids of types registered at run time are at least QMetaType::User.

Debug streaming (QDebug) and data streaming (QDataStream) of a type are available when its operator<< and operator>> exist and the stream classes are declared where the type is first used. Equality and ordering are detected the same way.

See also QVariant and QMetaTypeId.

Differences from Qt

The layout of QMetaTypeInterface is Nt's own. Enumerators of QMetaType::Type for classes that Nt does not have (such as QLocale, QRegularExpression and QModelIndex) are reserved, but no type is registered for them. The JSON classes are registered, but convert() has no conversions for them. QMetaType::QVersionNumber does not exist; QVersionNumber, QMargins and QMarginsF get an id at the first registration like any user type. There is no registerType(), registerComparators(), registerMutableView(), QMetaType::view() or support for smart-pointer metatypes. A type with no operator== compares equal in a QVariant only when both variants share the same stored value.

[static] bool QMetaType::convert(QMetaType fromType, const void *from, QMetaType toType, void *to)

Converts the value at from of the type fromType to the type toType, storing the result in the constructed value at to. Returns true on success.

A converter registered with registerConverter() takes precedence. Otherwise the built-in conversions apply:

  • Numbers, bool and QChar convert to each other. A floating-point number converts to an integer by rounding, and fails if it is not finite or does not fit.

  • QString and QByteArray convert to numbers (an integer, or a number with a fraction that is rounded) and to bool (false for an empty string, "0" and "false").

  • Numbers, bool, QChar, QDate, QTime, QDateTime, QUrl, QUuid, QVersionNumber and a QStringList of one element convert to QString; so does a QByteArray, as UTF-8.

  • QString converts to QByteArray (as UTF-8), QDate, QTime, QDateTime (ISO 8601), QUrl, QUuid, QVersionNumber and QStringList (one element).

  • QDateTime converts to QDate and QTime, and QDate to QDateTime.

  • QStringList, QByteArrayList and QVariantList convert to each other when each element converts; QVariantMap and QVariantHash convert to each other.

  • QPoint, QSize, QRect and QLine convert to and from their floating-point variants.

  • An enumeration converts to and from integers; with Q_ENUM() it also converts to and from its key name as a QString.

  • A sequential or associative container converts to QVariantList, QVariantMap or QVariantHash when its elements convert.

  • A pointer to a QObject-derived class converts to another one if the cast succeeds.

See also canConvert(), registerConverter() and QVariant::convert().
