Detailed Description

An error has a type, a D-Bus error name such as org.freedesktop.DBus.Error.UnknownMethod, and a text for people:

QDBusReply<QString> reply = iface.call("Name");
if (!reply.isValid())
    qWarning() << reply.error().name() << reply.error().message();

See also QDBusMessage and QDBusReply.

Differences from Qt

There is no QDebug stream operator. The errors that Nt itself generates use the same names as Qt's, so that peers which match on them work unchanged.
