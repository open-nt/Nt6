Detailed Description

A QMetaMethod describes a signal, a slot, an invokable method or a constructor that ntmoc found in a class. Get one from QMetaObject::method() or QMetaObject::indexOfMethod(), or for a signal from fromSignal().

const QMetaObject *mo = &QTimer::staticMetaObject;
QMetaMethod m = mo->method(mo->indexOfSlot("start(int)"));
qDebug() << m.methodSignature() << m.parameterCount();
m.invoke(&timer, Q_ARG(int, 100));

See also QMetaObject, QMetaProperty and QMetaEnum.

Differences from Qt

invokeOnGadget() is not available. Argument types are compared by name, as in Qt, so the types of a queued call must be registered with the meta-type system. A Qt::BlockingQueuedConnection call to an object in the calling thread runs the method directly, where Qt reports a deadlock.

Invokes this method on object and returns true if it could be invoked. The arguments val0, val1, val2, val3, val4, val5, val6, val7, val8 and val9, made with Q_ARG(), must match the parameters of the method in number and type, and returnValue, made with Q_RETURN_ARG(), receives the return value; its type must match the return type of the method. Returns false if the method is a constructor, if object is not an instance of the class of the method, or if the arguments do not fit.
