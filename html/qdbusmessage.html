Detailed Description

A message is a method call, a reply to one, an error or a signal. Create one with the static functions, add arguments with operator<<() and send it with QDBusConnection:

QDBusMessage call = QDBusMessage::createMethodCall(
    "org.example.Clock", "/clock", "org.example.Clock", "SetAlarm");
call << 7 << 30;
QDBusMessage reply = QDBusConnection::sessionBus().call(call);
if (reply.type() == QDBusMessage::ErrorMessage)
    qWarning() << reply.errorMessage();

QDBusMessage is implicitly shared.

See also QDBusConnection and QDBusReply.

Differences from Qt

There is no QDebug stream operator and no createSignal() overload taking only a path.
