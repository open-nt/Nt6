Detailed Description

QDebug is used to write human-readable diagnostics. Obtain a stream from qDebug(), qInfo(), qWarning() or qCritical() and write values to it with <<. The message is emitted when the stream, and every copy of it, is destroyed, so a statement such as

qDebug() << "value:" << 42 << QString("text");

produces one message, value: 42 "text". Spaces are inserted between values unless disabled with nospace(), and strings are quoted unless disabled with noquote().

A message is written to stderr followed by a newline, in the format set with qSetMessagePattern(), unless a handler was installed with qInstallMessageHandler(). That handler then receives the message type (QtDebugMsg, QtInfoMsg, QtWarningMsg, QtCriticalMsg or QtFatalMsg), a QMessageLogContext and the text instead. A QtFatalMsg message aborts the process after it is handled.

The same functions also have printf-style forms, such as qDebug("count: %d", n), and qFatal() takes a format string. A QLoggingCategory selects which messages are written; see qCDebug().

See also QMessageLogger, QMessageLogContext, QDebugStateSaver and QLoggingCategory.

Differences from Qt

There is no verbosity(), resetFormat() or swap(), no stream manipulators such as endl, and no << for QFlags, QSet, QPair, QStringView, QMetaEnum or the value classes. Containers supported are QList, QMap and QHash.

Member Function Documentation

[explicit] QDebug::QDebug(QtMsgType type)

Constructs a debug stream that emits a message of the given type when it is destroyed.

[explicit] QDebug::QDebug(QString *string)

Constructs a debug stream that appends its text to string when it is destroyed, instead of emitting a message. A space written after the last value is kept.

[explicit] QDebug::QDebug(QIODevice *device)

Constructs a debug stream that writes its text to device, as UTF-8, when it is destroyed, instead of emitting a message. A space written after the last value is kept.

QDebug::QDebug(const QDebug &)

Constructs a copy of another stream. The copies share one buffer, and the message is emitted when the last copy is destroyed.

QDebug::~QDebug()

Destroys the stream. If this is the last copy of the stream, the accumulated message is emitted, with a trailing space removed, and for QtFatalMsg the process is aborted. A stream for a QString or a QIODevice writes its text there instead.

bool QDebug::autoInsertSpaces() const

Returns true if spaces are inserted between values automatically.

See also setAutoInsertSpaces(), space() and nospace().

QDebug & QDebug::maybeQuote(char c = '"')

Writes the character c to the stream if quoting is enabled, and returns a reference to the stream.

See also quote() and noquote().

QDebug & QDebug::maybeSpace()

Writes a space character to the stream if spaces are enabled, and returns a reference to the stream.

See also space() and nospace().

QDebug & QDebug::noquote()

Disables quoting of strings and characters, and returns a reference to the stream. Strings are then written without escaping.

See also quote() and maybeQuote().

QDebug & QDebug::nospace()

Disables the automatic insertion of spaces between values, and returns a reference to the stream.

See also space() and maybeSpace().

QDebug & QDebug::operator<<(bool v)

QDebug & QDebug::operator<<(const QObject *o)

QDebug & QDebug::quote()

QDebug & QDebug::space()
