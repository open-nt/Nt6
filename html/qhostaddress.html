Detailed Description

QHostAddress holds an IPv4 or IPv6 address, or one of the special values in SpecialAddress. It does not perform name lookups; use QAbstractSocket::connectToHost() with a host name for that.

QHostAddress a("192.168.0.1");
quint32 ip = a.toIPv4Address();
QHostAddress any(QHostAddress::Any);

See also QAbstractSocket and QNetworkDatagram.

Differences from Qt

Scope IDs are not stored: a %zone suffix is ignored by setAddress(). There is no parseSubnet(), isInSubnet(), scopeId(), isUniqueLocalUnicast(), isSiteLocal() or isBroadcast(). toIPv4Address() and toString() are the only conversions, and there is no QDataStream or QDebug support.

enum QHostAddress::ConversionModeFlag

This enum describes the conversions that isEqual() may apply before comparing two addresses.

ConstantDescription
QHostAddress::ConvertV4MappedToIPv4Treat IPv4-mapped IPv6 addresses (::ffff:a.b.c.d) as the equivalent IPv4 address.
QHostAddress::ConvertV4CompatToIPv4Declared for source compatibility; not used.
QHostAddress::ConvertUnspecifiedAddressDeclared for source compatibility; not used.
QHostAddress::ConvertLocalHostTreat any two loopback addresses as equal.
QHostAddress::TolerantConversionEnables every conversion flag.
QHostAddress::StrictConversionNo conversion; the addresses must be identical.

See also ConversionMode and isEqual().

enum QHostAddress::SpecialAddress

This enum describes address types with a special meaning.

ConstantDescription
QHostAddress::NullThe null address object. Equivalent to QHostAddress().
QHostAddress::BroadcastThe IPv4 broadcast address, 255.255.255.255.
QHostAddress::LocalHostThe IPv4 localhost address, 127.0.0.1.
QHostAddress::LocalHostIPv6The IPv6 localhost address, ::1.
QHostAddress::AnyThe dual-stack any-address. A socket bound to it listens on all IPv4 and IPv6 interfaces.
QHostAddress::AnyIPv6The IPv6 any-address, ::. A socket bound to it listens on IPv6 interfaces only.
QHostAddress::AnyIPv4The IPv4 any-address, 0.0.0.0. A socket bound to it listens on IPv4 interfaces only.

bool QHostAddress::isEqual(const QHostAddress &other, ConversionMode mode = TolerantConversion) const

Returns true if this address is equal to other after applying the conversions enabled in mode; otherwise returns false.

bool QHostAddress::isGlobal() const

Returns true if the address is a globally routable unicast address, that is, not loopback, private, link-local, multicast or unspecified; otherwise returns false.

bool QHostAddress::isLinkLocal() const

Returns true if the address is an IPv4 link-local address (169.254.0.0/16) or an IPv6 link-local address (fe80::/10); otherwise returns false.

bool QHostAddress::isLoopback() const

Returns true if the address is an IPv4 address in 127.0.0.0/8, or the IPv6 loopback address (or its IPv4-mapped form); otherwise returns false.

bool QHostAddress::isMulticast() const

Returns true if the address is an IPv4 multicast address (224.0.0.0/4) or an IPv6 multicast address (ff00::/8); otherwise returns false.

bool QHostAddress::isNull() const

Returns true if the address is null, that is, it holds no address.

See also clear().

bool QHostAddress::setAddress(const QString &address)

This is an overloaded function.

Parses address as a dotted-decimal IPv4 or textual IPv6 address, ignoring surrounding whitespace and any %scope suffix. Returns true on success. On failure the address is cleared to a null address and the function returns false.

quint32 QHostAddress::toIPv4Address(bool *ok = nullptr) const

Returns the IPv4 address as a host-byte-order number. IPv4-mapped IPv6 addresses are converted. If ok is not null, it is set to true on success and false if the address has no IPv4 form, in which case 0 is returned.

See also toIPv6Address() and toString().

QHostAddress::toIPv6Address() const

Returns the address as an IPv6 address. An IPv4 address is returned in its IPv4-mapped form (::ffff:a.b.c.d); a null address yields all zeros.

See also toIPv4Address() and toString().

QString QHostAddress::toString() const

Returns the address as a string, in dotted-decimal form for IPv4 or in the usual compressed form for IPv6. Returns a null string for a null address.

See also setAddress().
