Detailed Description

QStringList is a QList<QString> with convenience functions for working with strings: join(), filter(), replaceInStrings(), removeDuplicates() and sort(). Lists are usually produced by QString::split() and combined back with join():

QStringList fields = QString("a,b,c").split(',');
fields << "d";
QString csv = fields.join(',');   // "a,b,c,d"

See also QString and QList.

Differences from Qt

QStringList derives from QList<QString> as in Qt 6. contains(), indexOf(), filter() and replaceInStrings() take plain QString arguments only: there are no QStringView, QLatin1StringView or QRegularExpression overloads. lastIndexOf() is the inherited QList one and has no case sensitivity argument. join() accepts a QString or QChar separator only.

bool QStringList::contains(const QString &s, Qt::CaseSensitivity cs = Qt::CaseSensitive) const

Returns true if the list contains the string s, using the case sensitivity cs; otherwise returns false.

See also indexOf().

QStringList QStringList::filter(const QString &needle, Qt::CaseSensitivity cs = Qt::CaseSensitive) const

Returns a list of the strings that contain the substring needle, using the case sensitivity cs.

See also QString::contains().

qsizetype QStringList::indexOf(const QString &s, qsizetype from = 0, Qt::CaseSensitivity cs = Qt::CaseSensitive) const

Returns the index position of the first string in the list equal to s, searching forward from index position from, or -1 if there is none. cs selects the case sensitivity.

See also contains().

QString QStringList::join(const QString &sep) const

Returns the strings in the list joined into one string, with sep inserted between consecutive strings. An empty list gives an empty string.

See also QString::split().

QStringList & QStringList::operator<<(const QStringList &l)

qsizetype QStringList::removeDuplicates()

Removes duplicate strings from the list, keeping the first occurrence of each, and returns the number of strings removed. Strings are compared case sensitively.

QStringList & QStringList::replaceInStrings(const QString &before, const QString &after, Qt::CaseSensitivity cs = Qt::CaseSensitive)

Replaces every occurrence of the string before with after in each string of the list, using the case sensitivity cs, and returns a reference to the list.

See also QString::replace().

void QStringList::sort(Qt::CaseSensitivity cs = Qt::CaseSensitive)

Sorts the list in ascending order, comparing strings with QString::compare() and the case sensitivity cs. The sort is not guaranteed to be stable.
