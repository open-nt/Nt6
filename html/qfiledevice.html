Detailed Description

QFileDevice implements the file-descriptor based reading, writing and seeking shared by QFile, QSaveFile and QTemporaryFile. It is not instantiated directly. Data is read and written straight through the operating system, without an additional buffer.

The last failure is available from error() and errorString().

See also QFile, QSaveFile, QTemporaryFile and QIODevice.

Differences from Qt

There are no permission or timestamp functions (permissions(), setPermissions(), fileTime(), setFileTime() and the Permission and FileTime enums), no memory mapping (map() and unmap()), and no FileHandleFlags. flush() calls fsync() on the descriptor instead of flushing a user-space buffer. The class is POSIX-only.

[override] QFileDevice::~QFileDevice()

Destroys the file device. It does not close the file; subclasses do so in their own destructors.

[override] bool QFileDevice::atEnd() const

Reimplements QIODevice::atEnd().

Returns true if the file is open and the position is at the end of the file with no buffered data left; otherwise returns false.

[override] qint64 QFileDevice::bytesAvailable() const

Reimplements QIODevice::bytesAvailable().

Returns the number of bytes between the current position and the end of the file, plus any buffered look-ahead data.

[override] bool QFileDevice::canReadLine() const

Reimplements QIODevice::canReadLine().

Returns true if the look-ahead buffer holds a complete line or the file is not at its end; otherwise returns false.

[override] void QFileDevice::close()

Reimplements QIODevice::close().

Closes the file and its descriptor. Does nothing if the file is not open.

FileError QFileDevice::error() const

Returns the file error status. The returned error is NoError if no error has occurred since the file was opened or unsetError() was called.

See also unsetError() and errorString().

QString QFileDevice::fileName() const

Returns the name set by QFile::setFileName() or to the QFile constructors.

See also QFile::setFileName().

bool QFileDevice::flush()

Flushes the file's pending data to disk by calling fsync() on the descriptor. Returns true if successful, or if the file is not open or does not support synchronizing; otherwise returns false.

See also close().

int QFileDevice::handle() const

Returns the native file descriptor of the open file, or -1 if the file is not open.

[protected] bool QFileDevice::openPath(const QString &path, OpenMode mode)

Opens the file at path in the given mode and stores its descriptor. Returns true on success. Otherwise sets error() and errorString() and returns false.

Append and Truncate imply WriteOnly. The file is created if it does not exist, unless ExistingOnly is given. NewOnly fails if the file already exists. Opening a device that is already open fails with OpenError.

Subclasses call this function from their open() reimplementations.

See also close().

[override] qint64 QFileDevice::pos() const

Reimplements QIODevice::pos().

Returns the current file position, or 0 if the file is not open.

[override, protected] qint64 QFileDevice::readData(char *data, qint64 maxSize)

Reimplements QIODevice::readData().

Reads up to maxSize bytes from the file descriptor into data, retrying when interrupted. Returns the number of bytes read, or -1 on error, in which case error() is set to ReadError.

[override, protected] qint64 QFileDevice::readLineData(char *data, qint64 maxSize)

Reimplements QIODevice::readLineData().

Reads a chunk of up to maxSize bytes into data, ending at the first newline, and leaves the file position just after it. Returns the number of bytes read.

bool QFileDevice::resize(qint64 sz)

Sets the file size to sz bytes. Returns true if the file was resized successfully; returns false if the file is not open or the operation fails. If sz is larger than the file, the extra bytes read as zero; if it is smaller, the file is cut.

See also size().

[override] bool QFileDevice::seek(qint64 offset)

Reimplements QIODevice::seek().

For random-access devices, this function sets the current position to offset, measured from the start of the file. Returns true on success. Returns false if the file is not open, offset is negative, or the position cannot be changed, in which case error() is set to PositionError.

[protected] void QFileDevice::setFileError(FileError e, const QString &text)

Sets the file error to e and the error string to text.

See also error() and setErrorString().

[override] qint64 QFileDevice::size() const

Reimplements QIODevice::size().

Returns the size of the file in bytes. If the file is not open, the size of the file at fileName() is returned. Returns 0 if the size cannot be determined.

void QFileDevice::unsetError()

Sets the file's error to NoError. The error string is not cleared.

See also error().

[override, protected] qint64 QFileDevice::writeData(const char *data, qint64 maxSize)

Reimplements QIODevice::writeData().

Writes up to maxSize bytes from data to the file descriptor, retrying on partial writes. Returns the number of bytes written, or -1 if nothing could be written, in which case error() is set to WriteError.
