Detailed Description

QMultiMap<Key, T> is like QMap, but insert() always adds a new item, so several values can be stored under the same key. Items with equal keys are kept in insertion order. values(key) returns all values stored under a key, and count(key) returns how many there are.

QMultiMap<QString, int> scores;
scores.insert("Alice", 10);
scores.insert("Alice", 20);
QList<int> aliceScores = scores.values("Alice"); // {10, 20}

See also QMap and QMultiHash.

Differences from Qt

QMultiMap is implemented on top of std::multimap and is not implicitly shared. Values stored under one key are returned in insertion order, whereas Qt returns the most recently inserted first. Unlike QMap it has no first(), last(), takeFirst() or const lowerBound()/upperBound() overloads.
