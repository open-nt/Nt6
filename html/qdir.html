Detailed Description

A QDir holds a directory path together with name filters, an entry filter and a sort order. Use it to list a directory, to create, remove and rename entries, and to convert between relative and absolute paths. Paths always use / as the separator.

QDir dir("/var/log");
dir.setNameFilters(QStringList() << "*.log");
const QStringList logs = dir.entryList(QDir::Files, QDir::Time);

See also QFileInfo and QStandardPaths.

Differences from Qt

Only POSIX paths are supported, so toNativeSeparators() and fromNativeSeparators() return their argument unchanged. There is no support for search paths (setSearchPaths(), addSearchPath(), searchPaths()) or nameFiltersFromString(). Drives is accepted but lists nothing, drives() returns only the root directory, and Modified is ignored. Name filters are case-insensitive unless CaseSensitive is set, and match() is always case-insensitive. LocaleAware is ignored when sorting. cd() resolves .. lexically and never follows symbolic links to do so.

enum QDir::Filter

Selects which entries entryList() and entryInfoList() return.

ConstantDescription
QDir::DirsList directories that match the name filters.
QDir::FilesList files.
QDir::DrivesAccepted for compatibility; nothing is listed for it.
QDir::NoSymLinksDo not list symbolic links.
QDir::AllEntriesList directories, files and drives.
QDir::TypeMaskA mask for the type bits Dirs, Files, Drives and NoSymLinks.
QDir::ReadableList entries the process can read. Applies only together with a permission filter.
QDir::WritableList entries the process can write. Applies only together with a permission filter.
QDir::ExecutableList entries the process can execute. Applies only together with a permission filter.
QDir::PermissionMaskA mask for Readable, Writable and Executable.
QDir::ModifiedAccepted for compatibility; ignored.
QDir::HiddenList hidden entries, whose names start with a dot.
QDir::SystemList entries that are neither files nor directories, such as devices and broken symbolic links.
QDir::AccessMaskA mask for the access bits Readable, Writable, Executable, Modified, Hidden and System.
QDir::AllDirsList all directories, ignoring the name filters.
QDir::CaseSensitiveMatch the name filters case-sensitively.
QDir::NoDotDo not list the . entry.
QDir::NoDotDotDo not list the .. entry.
QDir::NoDotAndDotDotDo not list . and ...
QDir::NoFilterUse the filter set with setFilter(). Pass this to entryList() to keep the QDir's own filter.

enum QDir::SortFlag

Selects the order of the entries returned by entryList() and entryInfoList().

ConstantDescription
QDir::NameSort by name.
QDir::TimeSort by modification time, newest first.
QDir::SizeSort by size, largest first.
QDir::UnsortedReturn the entries in directory order.
QDir::SortByMaskA mask for Name, Time, Size and Unsorted.
QDir::DirsFirstPut directories before files.
QDir::ReversedReverse the sort order.
QDir::IgnoreCaseCompare names case-insensitively.
QDir::DirsLastPut directories after files. Ignored if DirsFirst is set.
QDir::LocaleAwareAccepted for compatibility; ignored.
QDir::TypeSort by file suffix, then by name.
QDir::NoSortUse the order set with setSorting(). Pass this to entryList() to keep the QDir's own order.

QString QDir::absoluteFilePath(const QString &fileName) const

Returns fileName prefixed with the absolute path of the directory. If fileName is absolute, it is returned unchanged. The file does not have to exist.

QString QDir::absolutePath() const

Returns the absolute path of the directory, with . and .. components resolved lexically. Symbolic links are not resolved.

See also canonicalPath(), path() and cleanPath().

See also absolutePath() and QFileInfo::canonicalFilePath().

Changes the directory to dirName and returns true. Returns false, leaving the path unchanged, if dirName is not an existing directory. .. is resolved lexically.

See also cdUp() and setPath().

See also cd().

QFileInfoList QDir::entryInfoList(Filters filters = NoFilter, SortFlags sort = NoSort) const

Returns a QFileInfo for each entry in the directory that matches the directory's name filters and the given filters, sorted by sort. If filters is NoFilter, the directory's own filter is used; if sort is NoSort, its own sort order is used.

See also entryList(), setNameFilters(), setFilter() and setSorting().

Returns the names of the entries in the directory that match the directory's name filters and the given filters, sorted by sort. If filters is NoFilter, the directory's own filter is used; if sort is NoSort, its own sort order is used.

See also entryInfoList(), setNameFilters(), setFilter() and setSorting().
