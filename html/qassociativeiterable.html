Detailed Description

A QVariant that holds an associative container, such as QMap<QString, int>, QHash or std::map, converts to a QAssociativeIterable, which reads the entries as QVariant objects:

QVariant v = QVariant::fromValue(QMap<QString, int>{{"a", 1}, {"b", 2}});
QAssociativeIterable it = v.value<QAssociativeIterable>();
for (auto i = it.begin(); i != it.end(); ++i)
    qDebug() << i.key().toString() << i.value().toInt();

See also QSequentialIterable, QVariant and QMetaType.

Differences from Qt

The iterable works on a copy of the variant, so it is read-only: there is no insert() or remove(). There is no metaContainer() and no operator[]; use value().
