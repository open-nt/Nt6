Detailed Description

A QLineF describes a finite line (or line segment) by its two end points, stored as QPointF values. Angles are measured in degrees, counter-clockwise from the positive x axis; since the y axis points down, a positive angle turns the line upwards on screen.

See also QLine and QPointF.

Differences from Qt

Coordinates are always double, which is what qreal is in Nt. There are no QDebug or QDataStream stream operators.

Member Type Documentation

enum QLineF::IntersectionType

Describes the type of intersection found by intersects().

ConstantDescription
QLineF::NoIntersectionThe lines do not intersect, because they are parallel.
QLineF::BoundedIntersectionThe lines intersect at a point that lies within both line segments.
QLineF::UnboundedIntersectionThe lines would intersect if extended indefinitely, but the intersection point lies outside at least one of the segments.

See also intersects().

IntersectionType QLineF::intersects(const QLineF &l, QPointF *point = nullptr) const

Returns a value indicating whether this line and the line l intersect, and if so how.

If the lines are not parallel and point is not nullptr, it is set to the intersection point, even when the intersection is unbounded. If the lines are parallel, point is left unchanged.

See also IntersectionType.
