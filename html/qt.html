Detailed Description

It holds the enums shared by several classes, such as Qt::CaseSensitivity and Qt::TimeSpec.

Differences from Qt

Only the enums listed here exist. Qt's other Qt:: enums, such as the key, mouse and widget enums, belong to modules Nt does not provide.

Member Type Documentation

enum Qt::AspectRatioMode

This enum describes how to scale a rectangle or size to fit another.

ConstantDescription
Qt::IgnoreAspectRatioThe size is scaled freely; the aspect ratio is not preserved.
Qt::KeepAspectRatioThe size is scaled to the largest rectangle that fits inside the given size, preserving the aspect ratio.
Qt::KeepAspectRatioByExpandingThe size is scaled to the smallest rectangle that contains the given size, preserving the aspect ratio.

See also QSize::scaled().

enum Qt::CaseSensitivity

This enum selects whether a string comparison or search distinguishes upper and lower case.

ConstantDescription
Qt::CaseInsensitiveCase is ignored.
Qt::CaseSensitiveCase is significant.

enum Qt::ConnectionType

This enum describes how a signal is delivered to a slot.

ConstantDescription
Qt::AutoConnectionThe default. The slot is called directly if the receiver lives in the thread that emits the signal, and queued otherwise. The decision is made at emission time.
Qt::DirectConnectionThe slot is called immediately when the signal is emitted, in the emitting thread.
Qt::QueuedConnectionThe arguments are copied and the slot is called later from the event loop of the receiver's thread.
Qt::BlockingQueuedConnectionLike QueuedConnection, but the emitting thread blocks until the slot has returned. If the receiver lives in the emitting thread, the slot is called directly instead of deadlocking.

See also QObject::connect() and Signals and Slots.

enum Qt::DateFormat

This enum selects the textual format of dates and times.

The toString() and fromString() functions of QDate, QTime and QDateTime accept this enum.

ConstantDescription
Qt::TextDateA locale-independent text form such as Sat Nov 7 2026; the default.
Qt::ISODateISO 8601 extended format, such as 2026-11-07 and 20:10:14.
Qt::ISODateWithMsISO 8601 extended format with milliseconds, such as 20:10:14.844.
Qt::RFC2822DateThe RFC 2822 format, such as 07 Nov 2026.

enum Qt::FindChildOption

This enum controls how QObject::findChild() and QObject::findChildren() search. The FindChildOptions type is a typedef for QFlags<FindChildOption>.

ConstantDescription
Qt::FindDirectChildrenOnlyOnly direct children are searched.
Qt::FindChildrenRecursivelyAll descendants are searched.

typedef Qt::FindChildOptions

The FindChildOptions type is a typedef for QFlags<FindChildOption>. It stores an OR combination of FindChildOption values.

typedef Qt::HANDLE

An opaque thread handle: the value QThread::currentThreadId() returns, a void *.

typedef Qt::SplitBehavior

The SplitBehavior type is a typedef for QFlags<SplitBehaviorFlags>. It stores an OR combination of SplitBehaviorFlags values.

enum Qt::SplitBehaviorFlags

This enum controls whether empty parts are kept when splitting a string. The SplitBehavior type is a typedef for QFlags<SplitBehaviorFlags>.

ConstantDescription
Qt::KeepEmptyPartsEmpty parts are kept in the result.
Qt::SkipEmptyPartsEmpty parts are left out of the result.

enum Qt::TimerType

This enum describes the accuracy a timer should have.

ConstantDescription
Qt::PreciseTimerAccepted for compatibility; it has no effect.
Qt::CoarseTimerAccepted for compatibility; it has no effect.
Qt::VeryCoarseTimerAccepted for compatibility; it has no effect.

See also QBasicTimer and QTimer.

enum Qt::TimeSpec

This enum describes how a date and time is to be interpreted.

The QDateTime class uses this enum.

ConstantDescription
Qt::LocalTimeThe local time of the system.
Qt::UTCCoordinated Universal Time.
Qt::OffsetFromUTCA fixed offset in seconds from UTC.
Qt::TimeZoneDeclared for compatibility; Nt has no time zone database and QDateTime does not support it.

Member Variable Documentation

namespace Qt::Literals

The Qt::Literals inline namespace holds the user-defined literal operators of Nt, so they are found through using namespace Qt::Literals, using namespace Qt::StringLiterals or using namespace Qt. The string literals _s (a QString from a u"" literal) and _L1 (a QLatin1StringView or QChar from a Latin-1 literal) are provided.
