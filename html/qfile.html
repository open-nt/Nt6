Detailed Description

QFile opens a file by name and reads and writes it through the operating system's file descriptors. Set the name in the constructor or with setFileName(), then call open():

QFile file("data.txt");
if (file.open(QIODevice::ReadOnly)) {
    const QByteArray contents = file.readAll();
    file.close();
}

QFile also has static functions to check whether a file exists and to remove, rename and copy files. For text and binary data, use QTextStream and QDataStream on top of a QFile.

See also QFileDevice, QTextStream, QDataStream, QSaveFile and QTemporaryFile.

Differences from Qt

The constructors do not accept std::filesystem::path, and there are no open() overloads that take a FILE* or a file descriptor. The Text open flag is accepted but does not translate line endings. There is no symLinkTarget(), link(), moveToTrash(), readLink(), decodeName() or encodeName(). Static copy() refuses to overwrite an existing file, and rename() does not fall back to copying across filesystems. Permissions are not copied.

bool QFile::copy(const QString &newName)

Copies the file currently specified by fileName() to a file called newName, closing it first if it is open. Returns true if successful; otherwise returns false and sets error() to CopyError. The copy fails if a file named newName already exists.

See also rename() and remove().

[static] bool QFile::copy(const QString &fileName, const QString &newName)

This is an overloaded function.

Copies the file fileName to newName. Returns true if successful; otherwise returns false. The copy fails if a file named newName already exists.

See also copy().

bool QFile::exists() const

This is an overloaded function.

Returns true if the file specified by fileName() exists; otherwise returns false.

See also fileName() and setFileName().

[static] bool QFile::exists(const QString &fileName)

Returns true if the file specified by fileName exists; otherwise returns false.

See also remove().

[override] bool QFile::open(OpenMode mode)

Reimplements QFileDevice::open().

Opens the file named by fileName() using the given mode. Returns true if successful; otherwise returns false and sets error() to OpenError. It fails if no file name has been set, the file is already open, or the operating system refuses to open it.

See also QFileDevice::openPath(), close() and setFileName().

bool QFile::remove()

Removes the file specified by fileName(), closing it first if it is open. Returns true if successful; otherwise returns false and sets error() to RemoveError.

See also exists().

[static] bool QFile::remove(const QString &fileName)

This is an overloaded function.

Removes the file specified by fileName. Returns true if successful; otherwise returns false. The file is not moved to a trash.

See also remove() and exists().

bool QFile::rename(const QString &newName)

Renames the file currently specified by fileName() to newName, closing it first if it is open. Returns true if successful; otherwise returns false and sets error() to RenameError. On success, fileName() becomes newName.

See also exists().

[static] bool QFile::rename(const QString &oldName, const QString &newName)

This is an overloaded function.

Renames the file oldName to newName. Returns true if successful; otherwise returns false. An existing file at newName is replaced.

See also rename().

void QFile::setFileName(const QString &name)

Sets the name of the file. The name has no path, a relative path, or an absolute path. Does nothing if the file is open.

See also fileName() and exists().
