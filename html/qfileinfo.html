Detailed Description

A QFileInfo holds a path, relative or absolute, and queries the file system for information about it. The results are cached until refresh() is called or the path changes; use setCaching() to turn caching off.

QFileInfo fi("/usr/lib/libz.so.1.3");
fi.suffix();         // "3"
fi.completeSuffix(); // "so.1.3"
fi.baseName();       // "libz"

See also QDir and QFile.

Differences from Qt

Permissions are reported as QFileInfo::Permissions, with the same values as Qt's QFileDevice::Permission, because QFileDevice has no permission enum yet. There is no birthTime(), fileTime(), isNativePath(), isBundle(), isShortcut() or isJunction(). isReadable(), isWritable() and isExecutable() use access(2), which tests against the real rather than the effective user ID. absoluteFilePath() and absolutePath() are lexically cleaned without touching the file system.

Member Type Documentation

enum QFileInfo::Permission

Describes the permissions of a file. The owner and user values are identical and are both set from the owner permission bits.

ConstantDescription
QFileInfo::ReadOwnerThe file is readable by the owner.
QFileInfo::WriteOwnerThe file is writable by the owner.
QFileInfo::ExeOwnerThe file is executable by the owner.
QFileInfo::ReadUserThe file is readable by the user.
QFileInfo::WriteUserThe file is writable by the user.
QFileInfo::ExeUserThe file is executable by the user.
QFileInfo::ReadGroupThe file is readable by the group.
QFileInfo::WriteGroupThe file is writable by the group.
QFileInfo::ExeGroupThe file is executable by the group.
QFileInfo::ReadOtherThe file is readable by anyone.
QFileInfo::WriteOtherThe file is writable by anyone.
QFileInfo::ExeOtherThe file is executable by anyone.

See also permissions().

QDir QFileInfo::absoluteDir() const

Returns the file's directory as a QDir, built from absolutePath().

See also dir() and absolutePath().

QString QFileInfo::absoluteFilePath() const

Returns the absolute path of the file, including its name. The path is cleaned lexically, so . and .. components are resolved and symbolic links are not followed. Returns an empty string if the QFileInfo is empty.

See also canonicalFilePath() and filePath().

QString QFileInfo::absolutePath() const

Returns the absolute path of the file's directory, without the file name. The path is cleaned lexically.

See also path(), canonicalPath() and absoluteDir().

QString QFileInfo::baseName() const

Returns the file name without its directory path, up to the first dot. For archive.tar.gz this is archive.

See also completeBaseName() and completeSuffix().

bool QFileInfo::caching() const

Returns true if file information is cached; otherwise returns false.

See also setCaching().

QString QFileInfo::canonicalFilePath() const

Returns the canonical path of the file, including its name, with symbolic links and redundant components resolved. Returns an empty string if the file does not exist.

See also absoluteFilePath().

QString QFileInfo::canonicalPath() const

Returns the canonical path of the file's directory, without the file name. Returns an empty string if the file does not exist.

See also canonicalFilePath() and absolutePath().

QString QFileInfo::completeBaseName() const

Returns the file name without its directory path and without the last suffix. For archive.tar.gz this is archive.tar.

See also baseName() and suffix().

QString QFileInfo::completeSuffix() const

Returns the part of the file name after the first dot, or an empty string if there is no dot. For archive.tar.gz this is tar.gz.

See also suffix() and baseName().

QDir QFileInfo::dir() const

Returns the file's directory as a QDir, built from path().

See also absoluteDir() and path().

bool QFileInfo::exists() const

Returns true if the file exists; otherwise returns false. A dangling symbolic link does not exist.

See also isFile() and isDir().
