Detailed Description

Call start() or restart() to begin timing, then elapsed() or nsecsElapsed() to read the time since then. The timer uses a monotonic clock, so it is not affected by changes to the system time.

QElapsedTimer timer;
timer.start();
slowOperation();
qDebug() << "took" << timer.elapsed() << "ms";

See also QDeadlineTimer.

Differences from Qt

The timer is always based on std::chrono::steady_clock, so clockType() always returns MonotonicClock and isMonotonic() always returns true. There is no secsTo(), operator<() or durationElapsed(). hasExpired() treats an invalid timer as expired.

Member Function Documentation

[static] ClockType QElapsedTimer::clockType()

Returns the clock type that the timer uses. This is always MonotonicClock.

See also isMonotonic().

qint64 QElapsedTimer::elapsed() const

Returns the number of milliseconds since the timer was started, or 0 if the timer is invalid.

See also nsecsElapsed() and hasExpired().

bool QElapsedTimer::hasExpired(qint64 timeoutMs) const

Returns true if more than timeoutMs milliseconds have elapsed since the timer was started, or if the timer is invalid; otherwise returns false.

See also elapsed().

void QElapsedTimer::invalidate()

Marks the timer as invalid.

See also isValid().

[static] bool QElapsedTimer::isMonotonic()

Returns true if the clock is monotonic, which is always the case.

See also clockType().

bool QElapsedTimer::isValid() const

Returns true if start() or restart() has been called and the timer has not been invalidated; otherwise returns false.

See also invalidate().

qint64 QElapsedTimer::msecsSinceReference() const

Returns the start time of the timer as milliseconds since the clock's reference point.

See also msecsTo().

qint64 QElapsedTimer::msecsTo(const QElapsedTimer &o) const

Returns the number of milliseconds from this timer's start time to the start time of o. The result is negative if o was started earlier.

See also msecsSinceReference().

qint64 QElapsedTimer::nsecsElapsed() const

Returns the number of nanoseconds since the timer was started, or 0 if the timer is invalid.

See also elapsed().

qint64 QElapsedTimer::restart()

Restarts the timer and returns the number of milliseconds that had elapsed since it was started.

See also start() and elapsed().

void QElapsedTimer::start()

Starts the timer and makes it valid.

See also restart() and elapsed().
