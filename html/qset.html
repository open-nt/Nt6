Detailed Description

QSet<T> stores unique values and tests for membership in constant time on average. The values are kept in no particular order. The value type needs operator== and either a qHash() overload or a std::hash specialization.

QSet<QString> names;
names << "Alice" << "Bob";
names.insert("Alice"); // already present, no change
bool hasBob = names.contains("Bob");

See also QHash and QSetIterator.

Differences from Qt

QSet is implemented on top of std::unordered_set and has no implicit sharing. Its iterators are constant. The predicate passed to removeIf() is called with an iterator rather than with the value. There is no capacity(), squeeze(), constFind() or isSubsetOf(), and toList() is provided although it was removed from Qt 6.
