Detailed Description

QSslSocket is a QTcpSocket that encrypts what you write and decrypts what you read. Use it like any other socket, starting when encrypted() is emitted:

QSslSocket socket;
QObject::connect(&socket, &QSslSocket::encrypted, [&] {
    socket.write("GET / HTTP/1.1\r\nHost: example.com\r\n\r\n");
});
QObject::connect(&socket, &QIODevice::readyRead, [&] {
    qDebug() << socket.readAll();
});
socket.connectToHostEncrypted("example.com", 443);

Clients verify the server by default: the certificate must chain to a trusted CA and match the host name. On failure sslErrors() is emitted and the connection closes, with nothing sent. A slot can call ignoreSslErrors() to continue, which removes the protection TLS gives against impersonation, so pass the specific errors you expect, not none at all.

To encrypt an existing connection, as with STARTTLS, call startClientEncryption() once connected.

Servers need a certificate and key; see QSslServer.

See also QSslConfiguration, QSslServer and QSslCertificate.

Differences from Qt

Requires OpenSSL 1.1.1 or newer; when Nt is built without it, these classes are absent and QT_NO_SSL is defined. Only TLS 1.2 and 1.3 are available. connectToHostEncrypted() resolves the name synchronously, as QAbstractSocket::connectToHost() does. Only the OpenSSL backend exists, so there are no backend-selection functions, and no setCiphers(), PSK, OCSP or session resumption API. A peer that closes without a TLS shutdown is reported as an ordinary disconnect, so a protocol that delimits data by closing the connection cannot detect truncation from this class.

Member Type Documentation

enum QSslSocket::PeerVerifyMode

Selects how the peer's certificate is treated.

ConstantDescription
QSslSocket::VerifyNoneThe certificate is not requested or checked.
QSslSocket::QueryPeerThe certificate is requested, but problems are ignored.
QSslSocket::VerifyPeerThe certificate is required and must verify.
QSslSocket::AutoVerifyPeerVerifyPeer for clients, and VerifyNone for servers.

enum QSslSocket::SslMode

Describes what the socket is doing.

ConstantDescription
QSslSocket::UnencryptedModeThe connection is plain TCP.
QSslSocket::SslClientModeThe socket is the TLS client.
QSslSocket::SslServerModeThe socket is the TLS server.

[slot] void QSslSocket::ignoreSslErrors()

This is an overloaded function.

Continues the connection despite every verification problem. Call this from a slot connected to sslErrors(), after looking at the errors. It removes the protection TLS gives against impersonation.
