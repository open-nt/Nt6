Detailed Description

A QRandomGenerator produces 32-bit and 64-bit random numbers. Generators that are constructed or seeded explicitly are deterministic: the same seed always gives the same sequence, which is useful for tests. The generators returned by system() and global() are not.

int roll = QRandomGenerator::global()->bounded(1, 7);

The class meets the requirements of a C++ UniformRandomBitGenerator, so it can be passed to the standard <random> distributions and to std::shuffle.

A seeded QRandomGenerator is not thread-safe. The objects returned by system() and global() are.

See also QUuid.

Differences from Qt

There is no QRandomGenerator64, no operator==, operator<< or operator>> on the generator, no constructor taking a std::seed_seq, and no bounded() overload with two quint64 limits. A seeded generator uses std::mt19937. system() reads from getrandom(2), and global() is guarded by a mutex rather than being thread-local.

QRandomGenerator::QRandomGenerator(quint32 seedValue = 1)

Constructs a generator seeded from the len values at seedBuffer. The seed values are mixed with std::seed_seq, so the sequence is fully determined by them.

[static] QRandomGenerator * QRandomGenerator::global()

Returns the process-wide pseudo-random generator, which is seeded once from system(). It is thread-safe but not suitable for cryptographic use.

See also system() and securelySeeded().

[static, constexpr] result_type QRandomGenerator::max()

Returns the largest value that generate() can return, 0xffffffff.

See also min().

[static, constexpr] result_type QRandomGenerator::min()

Returns the smallest value that generate() can return, 0.

result_type QRandomGenerator::operator()()

Returns a random 32-bit value, the same as generate(). This lets the generator be used with the C++ standard library's distributions.

[static] QRandomGenerator QRandomGenerator::securelySeeded()

Returns a new generator that is seeded with random data from system().

See also system() and global().

void QRandomGenerator::seed(quint32 s = 1)

Reseeds the generator with s, which makes it a deterministic generator.

See also discard().

[static] QRandomGenerator * QRandomGenerator::system()

Returns the process-wide generator that reads from the operating system's random number source. It is cryptographically secure and thread-safe, but slower than global().

See also global() and securelySeeded().
