Detailed Description

A QLatin1StringView refers to a sequence of Latin-1 bytes without owning or copying them, so the viewed memory must outlive it. It is mainly used to pass 8-bit literals to QString functions without an intermediate conversion. QLatin1String is an alias for this class.

See also QString and QLatin1Char.

Differences from Qt

Only construction, data access, size() and the subscript operators are provided. Qt's searching, comparison, slicing and iteration functions, the comparison operators and the QLatin1StringView(QByteArrayView) constructor are not available.

[constexpr] QLatin1StringView::QLatin1StringView()

Constructs an empty Latin-1 string view.

[constexpr] QLatin1StringView::QLatin1StringView(const char *s)

Constructs a view of the null-terminated string s. The length is determined by scanning for the terminator; a null s gives an empty view.

[constexpr] QLatin1StringView::QLatin1StringView(const char *s, qsizetype len)

This is an overloaded function.

Constructs a view of the first len bytes of s.

QLatin1StringView::QLatin1StringView(const QByteArray &b)

This is an overloaded function.

Constructs a view of the contents of the byte array b.

[constexpr] QChar QLatin1StringView::at(qsizetype i) const

Returns the character at index position i as a QChar. i must be a valid index; no bounds checking is done.

[constexpr] const char * QLatin1StringView::data() const

Returns a pointer to the first byte of the viewed string. The data is not necessarily null-terminated.

See also latin1() and size().

[constexpr] bool QLatin1StringView::isEmpty() const

Returns true if the view has no characters; otherwise returns false.

See also size().

[constexpr] const char * QLatin1StringView::latin1() const

Returns a pointer to the first byte of the viewed string.

See also data().

[constexpr] QChar QLatin1StringView::operator[](qsizetype i) const

Returns the character at index position i. This is the same as at().

[constexpr] qsizetype QLatin1StringView::size() const

Returns the number of bytes in the view.

See also isEmpty().
