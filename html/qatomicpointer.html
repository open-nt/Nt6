Detailed Description

QAtomicPointer<T> wraps a std::atomic<T *>. It is used for lock-free publication of pointers between threads:

QAtomicPointer<Config> current;

void publish(Config *c) { current.storeRelease(c); }
Config *get() { return current.loadAcquire(); }

See also QAtomicInteger.

Differences from Qt

Only a subset of the Qt operations is provided: there are no fetchAndStoreRelaxed(), fetchAndAddRelaxed(), testAndSetRelaxed(), testAndSetAcquire() or testAndSetRelease() functions, no testAndSet overloads that report the current value, and no copy constructor or copy assignment.
