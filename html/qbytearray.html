Detailed Description

QByteArray stores raw bytes, or 8-bit text, in a contiguous buffer. It is used wherever binary data is needed, such as I/O buffers, hashes and encoded text.

QByteArray ba("Hello");
ba.append(", world");
ba.replace("world", "Nt");
// ba == "Hello, Nt"

A QByteArray can be null or empty. A null array is one that was default constructed, constructed from a null const char *, or cleared; a null array is also empty.

See also QList.

Differences from Qt

The bytes are stored in a std::string and the array is not implicitly shared, so copies are deep and fromRawData() copies the data. There is no QByteArrayView, QString conversion, slice(), nullTerminate(), isLower()/\c isUpper(), fromBase64Encoding() or percentDecoded(), and no overloads of insert() or prepend() taking a count and a character. split() takes a single char separator and always keeps empty parts. fromBase64() ignores its options argument and accepts both the standard and URL-safe alphabets. The conversions toStdString() and stdString() are Nt additions. Indexes are qsizetype but are not range-checked.

Member Type Documentation

enum QByteArray::Base64Option

These options change how toBase64() encodes data and how fromBase64() decodes it.

ConstantDescription
QByteArray::Base64EncodingUse the standard Base64 alphabet, with + and / as the last two characters.
QByteArray::Base64UrlEncodingUse the URL-safe Base64 alphabet, with - and _ as the last two characters.
QByteArray::KeepTrailingEqualsKeep the = padding at the end of the encoded data.
QByteArray::OmitTrailingEqualsOmit the = padding at the end of the encoded data.

typedef QByteArray::Base64Options

The Base64Options type is a typedef for QFlags<Base64Option>. It stores an OR combination of Base64Option values.

QByteArray QByteArray::mid(qsizetype pos, qsizetype len = -1) const

Returns a byte array containing len bytes from this byte array, starting at index position pos. If len is negative, or if pos + len is beyond the end of the array, all bytes from pos to the end are returned. If pos is negative, it is treated as 0 and len is reduced accordingly. If pos is beyond the end of the array, an empty, non-null byte array is returned.

See also left(), right() and sliced().

qlonglong QByteArray::toLongLong(bool *ok = nullptr, int base = 10) const

Returns the byte array converted to a long long using the given base, which must be between 2 and 36, or 0 to detect the base from the prefix. If ok is not nullptr, it is set to true if the conversion succeeded and to false otherwise. Returns 0 on failure.

See also number(), toULongLong() and toInt().

QByteArray QByteArray::toLower() const

Returns a lowercase copy of the byte array. Only the ASCII letters A to Z are converted; all other bytes are left unchanged.

See also toUpper().

QByteArray QByteArray::toPercentEncoding(const QByteArray &exclude = QByteArray(), const QByteArray &include = QByteArray(), char percent = '%') const

Returns a percent-encoded copy of the byte array. The unreserved characters A-Z a-z 0-9 - . _ ~ and the bytes in exclude are left as they are, unless they also occur in include. Every other byte is replaced by percent followed by two uppercase hex digits.

See also fromPercentEncoding().
