Detailed Description

QDBusInterface calls methods of a remote object by name, without a class written for the interface:

QDBusInterface clock("org.example.Clock", "/clock", "org.example.Clock");
QDBusReply<QString> now = clock.call("Now");
clock.setProperty("Volume", 7);

When it is constructed, QDBusInterface asks the remote object for its introspection data. The arguments of call() and the values of setProperty() are then converted to the types the interface declares, so that clock.call("SetAlarm", 7) sends a uint if the method takes one.

See also QDBusAbstractInterface and QDBusConnection::connect().

Differences from Qt

QDBusInterface has no meta-object built from the introspection data, so its methods, signals and properties are not visible to QMetaObject and QObject::connect() with SIGNAL() cannot reach the remote signals; connect to them with QDBusConnection::connect(). property() and setProperty() work as in QDBusAbstractInterface.
