Detailed Description

A QDeadlineTimer stores a point in time, or the special value Forever that never expires. Use hasExpired() to test whether the deadline has passed and remainingTime() to find out how long is left, for example to pass a timeout to a wait function.

QDeadlineTimer deadline(500);
while (!deadline.hasExpired())
    poll();

See also QElapsedTimer.

Differences from Qt

The timer is based on std::chrono::steady_clock. The Qt::TimerType argument of the constructors and setters is accepted but ignored. There is no QDeadlineTimer::current(), addNSecs(), deadline(), setDeadline(), setPreciseDeadline(), operator+(), comparison operators, or constructor taking a std::chrono::duration.

Member Function Documentation

QDeadlineTimer::QDeadlineTimer(Qt::TimerType = Qt::CoarseTimer)

Constructs a deadline that is already expired. The timer type is ignored.

See also setRemainingTime().

QDeadlineTimer::QDeadlineTimer(ForeverConstant, Qt::TimerType = Qt::CoarseTimer)

Constructs a deadline that never expires. The timer type is ignored.

See also isForever().

QDeadlineTimer::QDeadlineTimer(qint64 msecs, Qt::TimerType = Qt::CoarseTimer)

Constructs a deadline that expires in msecs milliseconds. A negative value means the deadline never expires. The timer type is ignored.

See also setRemainingTime().

bool QDeadlineTimer::hasExpired() const

Returns true if the deadline has passed; otherwise returns false. A deadline that never expires has not expired.

See also remainingTime().

bool QDeadlineTimer::isForever() const

Returns true if the deadline never expires; otherwise returns false.

qint64 QDeadlineTimer::remainingTime() const

Returns the time left until the deadline in milliseconds, rounded up, or -1 if the deadline never expires. The result is 0 once the deadline has passed.

See also remainingTimeNSecs().

qint64 QDeadlineTimer::remainingTimeNSecs() const

Returns the time left until the deadline in nanoseconds, or -1 if the deadline never expires. The result is 0 once the deadline has passed.

See also remainingTime().

void QDeadlineTimer::setPreciseRemainingTime(qint64 secs, qint64 nsecs = 0, Qt::TimerType = Qt::CoarseTimer)

Sets the deadline to secs seconds and nsecs nanoseconds from now. The timer type is ignored.

See also setRemainingTime().

void QDeadlineTimer::setRemainingTime(qint64 msecs, Qt::TimerType = Qt::CoarseTimer)

Sets the deadline to msecs milliseconds from now. A negative value means the deadline never expires. The timer type is ignored.

See also setPreciseRemainingTime().

Clock::time_point QDeadlineTimer::timePoint() const

Returns the deadline as a time point of the timer's clock. The value is meaningless if the deadline never expires.

See also isForever().
