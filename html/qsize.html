Detailed Description

A size is specified by a width() and a height(), both stored as int. A default-constructed size is invalid, with a width and height of -1. Use QSizeF for floating-point dimensions.

See also QSizeF, QPoint and QRect.

Differences from Qt

There are no QDebug or QDataStream stream operators, and no grownBy() or shrunkBy().

QSize QSize::scaled(const QSize &s, Qt::AspectRatioMode mode) const

Returns this size scaled to a rectangle with the given size s, according to the given mode.

If mode is Qt::IgnoreAspectRatio, or this size has a zero width or height, s is returned unchanged. With Qt::KeepAspectRatio the result fits inside s; with Qt::KeepAspectRatioByExpanding it covers s.

See also scale().
