Detailed Description

QAbstractSocket is a non-blocking, event-loop driven socket built on POSIX sockets. Call connectToHost() to connect, or bind() to receive datagrams, then react to the connected(), readyRead() and disconnected() signals:

QTcpSocket socket;
QObject::connect(&socket, &QTcpSocket::connected, [&] { socket.write("hello\n"); });
socket.connectToHost("localhost", 8080);

The waitFor...() functions block the calling thread by polling the socket and can be used without an event loop.

See also QTcpSocket, QUdpSocket and QTcpServer.

Differences from Qt

Host names are resolved synchronously inside connectToHost(), so hostFound() is emitted before the function returns. There is no proxy or SSL support: the proxy functions, proxyAuthenticationRequired() and the related error values are declared or omitted but never produced. pauseMode(), setPauseMode(), resume(), setLocalPort() and the other protected peer/local setters are not available. Sockets must be used from a single thread.

QAbstractSocket::QAbstractSocket(SocketType socketType, QObject *parent)

Creates a new abstract socket of type socketType with the given parent. The socket starts in the UnconnectedState and no operating system socket exists until connectToHost() or bind() is called.

[override] QAbstractSocket::~QAbstractSocket()

Destroys the socket and closes the underlying operating system socket without emitting disconnected().

void QAbstractSocket::abort()

Aborts the current connection and discards any pending outgoing data, then closes the socket.

See also disconnectFromHost() and close().

bool QAbstractSocket::bind(const QHostAddress &address, quint16 port = 0, BindMode mode = DefaultForPlatform)

Binds the socket to address on port using the given mode. A port of 0 lets the system choose a free port. Returns true on success, after which the socket is in BoundState; otherwise sets the error and returns false.

For UDP sockets, the socket is opened for reading and writing once bound. Binding to QHostAddress::Any creates a dual-stack socket when the system supports it.

See also localPort() and localAddress().

bool QAbstractSocket::bind(quint16 port = 0, BindMode mode = DefaultForPlatform)

This is an overloaded function.

Binds to QHostAddress::Any on port using the given mode.

[virtual] void QAbstractSocket::connectToHost(const QString &hostName, quint16 port, OpenMode mode = ReadWrite, NetworkLayerProtocol protocol = AnyIPProtocol)

Attempts to make a connection to hostName on the given port. The protocol parameter restricts the lookup to IPv4 or IPv6 addresses.

The host name is resolved synchronously and hostFound() is emitted. The socket then enters ConnectingState and connected() is emitted once the connection is established, or errorOccurred() if every address fails. The socket is opened in mode.

See also connected(), waitForConnected() and disconnectFromHost().

[virtual] void QAbstractSocket::connectToHost(const QHostAddress &address, quint16 port, OpenMode mode = ReadWrite)

This is an overloaded function.

Attempts to make a connection to address on the given port. No host name lookup is performed, so hostFound() is not emitted.

[virtual, protected] void QAbstractSocket::readActivated()

Called when the operating system socket becomes readable. TCP sockets read the available bytes into the internal buffer and emit readyRead(); a zero-byte read closes the socket with RemoteHostClosedError. UDP sockets only emit readyRead() and leave the datagram queued.

See also setReadBufferSize().

void QAbstractSocket::setReadBufferSize(qint64 size)

Sets the size of the internal read buffer to size bytes. If the buffer is full, the socket stops reading from the network until the application consumes data. A size of 0 (the default) means the buffer is unlimited.

[override] bool QAbstractSocket::waitForBytesWritten(int msecs = 30000)

[virtual] bool QAbstractSocket::waitForConnected(int msecs = 30000)

Waits until the socket is connected, up to msecs milliseconds (a negative value waits forever). Returns true if the connection has been established; otherwise returns false and, on a timeout, sets SocketTimeoutError.

See also connectToHost() and connected().

[virtual] bool QAbstractSocket::waitForDisconnected(int msecs = 30000)

Waits until the socket has disconnected, up to msecs milliseconds. Returns true if the connection has been closed; otherwise returns false.

See also disconnectFromHost() and disconnected().

[override] bool QAbstractSocket::waitForReadyRead(int msecs = 30000)

Reimplements QIODevice::waitForReadyRead().

Blocks until new data is available for reading and readyRead() has been emitted, or until msecs milliseconds have passed. Returns true if data arrived; otherwise returns false.

See also waitForBytesWritten().

[override, protected] qint64 QAbstractSocket::writeData(const char *data, qint64 maxSize)

Reimplements QIODevice::writeData().
