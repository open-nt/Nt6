Detailed Description

A JSON array is a list of values. You can append and remove values from the array, and read or replace the value at any index.

QJsonArray array = {1, 2.5, "three"};
array.append(true);
array.insert(0, QJsonValue::Null);
for (const QJsonValue &v : array)
    use(v);

QJsonArray is implicitly shared: copies are cheap and the data is copied when one of them is modified. It is reentrant, so separate arrays can be used from separate threads, but one array must not be modified while another thread reads it or a copy that shares its data.

The iterators are index based. Reading or assigning through an iterator is valid for as long as the array has at least that many elements, and an insertion or removal before the position moves the element the iterator refers to, so, as with QList, treat any iterator at or after a modified position as invalid. Assigning through *it does not invalidate other iterators.

See also QJsonValue, QJsonObject and QJsonDocument.

Differences from Qt

Out-of-range indexes never assert: at() returns an undefined value, and insert(), replace() and removeAt() do nothing. The iterators hold the array and an index instead of a pointer, so copying the array while an iterator is alive is harmless: writes through a non-const iterator go to the array it came from.
