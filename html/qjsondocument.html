Detailed Description

A QJsonDocument holds a complete JSON document, which is either an array or an object. It can be read from UTF-8 text with fromJson() and written back with toJson().

QJsonParseError err;
QJsonDocument doc = QJsonDocument::fromJson("{\"a\": [1, 2, 3]}", &err);
if (doc.isObject())
    qDebug() << doc["a"][1].toInt();   // 2
QByteArray text = doc.toJson(QJsonDocument::Compact);

The parser follows RFC 8259: the text must be valid UTF-8, strings may use backslash-u escapes with four hex digits, including surrogate pairs, and there must be no trailing commas, comments or unquoted keys. A leading UTF-8 byte order mark is skipped. Documents nest at most 1024 levels deep. Integers that fit in 2^53 are kept exact, other numbers become doubles, and a number that does not fit in a double is an error.

A document written with Indented uses four spaces per level, puts each value on a line of its own and ends with a line feed; Compact writes no white space at all. Object keys appear in sorted order.

See also QJsonValue, QJsonObject, QJsonArray and QJsonParseError.

Differences from Qt

There is no fromRawData(), rawData() or fromBinaryData(), which Qt 6 removed too. Top-level scalars are rejected as in Qt. A raw control character in a string is rejected as IllegalValue. A lone surrogate written with an escape is accepted and is written back as U+FFFD, the replacement character.

Member Type Documentation

enum QJsonDocument::JsonFormat

The formats toJson() can write.

ConstantDescription
QJsonDocument::IndentedDefines human readable output as follows:
{
    "Array": [
        true,
        999
    ],
    "Key": "Value"
}
ConstantDescription
QJsonDocument::CompactDefines a compact output as follows:
{"Array":[true,999],"Key":"Value"}

[static] QJsonDocument QJsonDocument::fromJson(const QByteArray &json, QJsonParseError *error = nullptr)

Parses json as UTF-8 encoded JSON and returns the document. If the text is not a valid document the result is null, and if error is not null it receives the reason and the offset at which it was found.

See also toJson() and QJsonParseError.

[static] QJsonDocument QJsonDocument::fromVariant(const QVariant &variant)

Converts variant to a document. A QVariantMap or QVariantHash gives a document that holds an object, and a QVariantList or QStringList one that holds an array; the contents are converted with QJsonValue::fromVariant(). Any other variant gives a null document.

See also toVariant(), QJsonObject::fromVariantMap() and QJsonArray::fromVariantList().

bool QJsonDocument::isArray() const

Returns true if the document holds an array.

See also array() and isObject().

bool QJsonDocument::isEmpty() const

Returns true if the document has no content. A document made from an empty array or object is not empty; only a null document is.

See also isNull().

bool QJsonDocument::isNull() const

Returns true if the document is null: it was default constructed, or it came from text that could not be parsed.

See also isEmpty().

bool QJsonDocument::isObject() const

Returns true if the document holds an object.

QByteArray QJsonDocument::toJson(JsonFormat format = Indented) const

Converts the document to UTF-8 JSON text in the given format. A null document gives an empty byte array.

QVariant QJsonDocument::toVariant() const

Converts the document to a QVariantMap if it holds an object, or to a QVariantList if it holds an array. A null document gives an invalid QVariant.
