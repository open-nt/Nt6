Detailed Description

A connection talks to a bus, usually the session bus or the system bus, or directly to one peer. Through it a program calls methods of remote objects, exports objects of its own, claims service names and receives signals:

QDBusConnection bus = QDBusConnection::sessionBus();
if (!bus.isConnected()) {
    std::fprintf(stderr, "No session bus: %s\n", qPrintable(bus.lastError().message()));
    return 1;
}
auto *clock = new Clock;
new ClockAdaptor(clock);
bus.registerObject("/clock", clock);
if (!bus.registerService("org.example.Clock")) {
    std::fprintf(stderr, "org.example.Clock is taken: %s\n", qPrintable(bus.lastError().message()));
    return 1;
}

A client calls the exported object:

QDBusConnection bus = QDBusConnection::sessionBus();
QDBusInterface clock("org.example.Clock", "/clock", "org.example.Clock", bus);
QDBusReply<QString> now = clock.call("Now");
if (!now.isValid()) {
    std::fprintf(stderr, "Cannot reach the clock: %s\n", qPrintable(now.error().message()));
    return 1;
}
std::printf("It is %s, volume %d\n", qPrintable(now.value()), clock.property("volume").toInt());

QDBusConnection is a handle to a shared connection: copies refer to the same one, and it can be used from any thread. Connections to a bus are identified by a name, so QDBusConnection(name) returns one made earlier with connectToBus().

Every connection is serviced by one thread that Nt starts. Calls to exported objects and signals for slots are delivered through the event loop of the thread that the receiving object lives in, so that thread must run an event loop. A blocking call() does not run the calling thread's event loop, except with QDBus::BlockWithGui; a blocking call to an object that this connection exports and that lives in the calling thread is delivered directly.

See also QDBusAbstractInterface, QDBusAbstractAdaptor, QDBusServer and Using Nt D-Bus.

Differences from Qt

Only unix: addresses (path, abstract and runtime, and dir or tmpdir for a server) are supported; tcp:, nonce-tcp:, launchd: and autolaunch: are not. Authentication uses the EXTERNAL mechanism, and ANONYMOUS if a server allows it; DBUS_COOKIE_SHA1 is not available. The signals of objects that ExportChildObjects exports are not relayed, and adaptors and children added after registerObject() are found for calls but their signals are not relayed. There is no sender() and no registerRoot(); QDBus::AutoDetect blocks like QDBus::Block. A connection that a QDBusServer accepted is closed when its last QDBusConnection is destroyed.

QDBusPendingCall QDBusConnection::asyncCall(const QDBusMessage &message, int timeout = -1) const

Sends message and returns an object that follows the call. The call fails after timeout milliseconds, or 25 seconds if it is -1.

See also QDBusPendingCallWatcher and QDBusPendingReply.

QString QDBusConnection::baseService() const

Returns the unique name that the bus gave this connection, such as :1.42. It is empty for a connection to a peer.

QDBusMessage QDBusConnection::call(const QDBusMessage &message, QDBus::CallMode mode = QDBus::Block, int timeout = -1) const

Sends message and waits as mode says for the reply, which it returns. The call fails with NoReply after timeout milliseconds, or 25 seconds if it is -1. With QDBus::NoBlock the function returns at once.

See also asyncCall() and QDBusReply.

bool QDBusConnection::callWithCallback(const QDBusMessage &message, QObject *receiver, const char *returnMethod, const char *errorMethod, int timeout = -1) const

Sends the call message and returns at once. When the reply arrives, returnMethod of receiver is called with its arguments; on an error, errorMethod is called with a QDBusError and, if it takes one, the QDBusMessage. Name the slots with SLOT(). The call fails after timeout milliseconds, or the default of 25 seconds if it is -1. Returns true if the call was sent.

bool QDBusConnection::callWithCallback(const QDBusMessage &message, QObject *receiver, const char *slot, int timeout = -1) const

This is an overloaded function.

Sends message and calls slot of receiver with the reply. Errors are ignored. timeout is in milliseconds.

bool QDBusConnection::connect(const QString &service, const QString &path, const QString &interface, const QString &name, QObject *receiver, const char *slot)

Connects the signal name of interface, emitted by the object at path of service, to slot of receiver, named with SLOT() or SIGNAL(). An empty argument matches anything. The slot receives the leading arguments of the signal that it has parameters for, and the QDBusMessage if its last parameter is one. Returns true on success.

See also disconnect().

bool QDBusConnection::connect(const QString &service, const QString &path, const QString &interface, const QString &name, const QString &signature, QObject *receiver, const char *slot)

This is an overloaded function.

Connects only to signals whose arguments have the D-Bus signature. service, path, interface, name, receiver and slot are as above.

bool QDBusConnection::connect(const QString &service, const QString &path, const QString &interface, const QString &name, const QStringList &argumentMatch, const QString &signature, QObject *receiver, const char *slot)

This is an overloaded function.

Connects only to signals whose leading string arguments equal argumentMatch; an empty string in the list matches any value. service, path, interface, name, signature, receiver and slot are as above.
