Detailed Description

Subclass it to write a proxy class for one remote interface: methods call callWithArgumentList() or asyncCall(), and signals that the class declares are emitted when the remote object emits the D-Bus signal of the same name:

class ClockInterface : public QDBusAbstractInterface {
    Q_OBJECT
public:
    explicit ClockInterface(const QDBusConnection &connection, QObject *parent = nullptr)
        : QDBusAbstractInterface("org.example.Clock", "/clock", "org.example.Clock", connection, parent) {}

    QDBusPendingReply<QString> Now() { return asyncCall("Now"); }
    QDBusPendingReply<> SetAlarm(int seconds, const QString &message) {
        return asyncCall("SetAlarm", seconds, message);
    }

signals:
    void alarm(const QString &message); // emitted when the remote clock emits it
};

QDBusInterface is a ready-made subclass for interfaces known only at run time.

See also QDBusInterface and QDBusConnection.

Differences from Qt

property() and setProperty() hide those of QObject and read and write the remote properties; call them through a QDBusAbstractInterface pointer or reference. A subclass relays every signal of the remote interface that it declares, whether connected or not. There is no qdbusxml2cpp to generate subclasses.
