Detailed Description

Every class that declares Q_OBJECT or Q_GADGET and goes through ntmoc has a static QMetaObject, staticMetaObject, that describes its class name, base class, signals, slots, invokable methods, properties, enumerators and class information. For a QObject, metaObject() returns the meta-object of its dynamic type.

const QMetaObject *mo = obj->metaObject();
for (int i = mo->propertyOffset(); i < mo->propertyCount(); ++i)
    qDebug() << mo->property(i).name();

Methods and properties are numbered across the inheritance chain: the base class has the lowest indexes, and methodOffset() and propertyOffset() give the first index of this class. Signals come first in a class, then slots, then Q_INVOKABLE methods, each in declaration order. A method with default arguments gets one extra entry for each shorter call.

See also QMetaMethod, QMetaProperty, QMetaEnum, QMetaClassInfo, QObject and Meta-Object System.

Differences from Qt

The layout of the public d data member is Nt's own and is not binary-compatible with Qt, and the code that ntmoc generates differs from that of Qt's moc. There are no qt_metacast() and qt_metacall() functions, no QMetaObject::tr() or changeGuard(), and qobject_cast() stays a wrapper around dynamic_cast. invokeMethod() has no overloads that take a pointer to a member function; pass a name or a functor. A class that ntmoc did not process has no meta-object of its own: QObject::metaObject() returns that of its nearest base class that has one.

[static] void QMetaObject::activate(QObject *sender, int signal_index, void **argv)

Emits the signal with the index signal_index of sender, with the arguments at argv, where argv[1] is the first one. argv[0] is reserved for a return value and is unused for signals. This is the call that a signal's generated body makes in Qt; Nt's ntmoc output does not use it, but code that does works.

See also QObject::connect().

[static] void QMetaObject::connectSlotsByName(QObject *o)

Connects signals to slots by name, for each slot of o that is named on_<object name>_<signal name>(...). The object name is that of o or of one of its descendants, and the signal is a signal of that object whose arguments are compatible with the slot. A slot that finds no signal prints a warning.

See also QObject::setObjectName().

[static] bool QMetaObject::invokeMethod(QObject *obj, const char *member, Qt::ConnectionType type, QGenericReturnArgument ret, QGenericArgument val0 = QGenericArgument(nullptr), QGenericArgument val1 = QGenericArgument(), QGenericArgument val2 = QGenericArgument(), QGenericArgument val3 = QGenericArgument(), QGenericArgument val4 = QGenericArgument(), QGenericArgument val5 = QGenericArgument(), QGenericArgument val6 = QGenericArgument(), QGenericArgument val7 = QGenericArgument(), QGenericArgument val8 = QGenericArgument(), QGenericArgument val9 = QGenericArgument())

Invokes the signal, slot or invokable method member of obj and returns true if it could be invoked. member is the name of the method without its parameters. The arguments val0, val1, val2, val3, val4, val5, val6, val7, val8 and val9, made with Q_ARG(), select the overload by their types, and ret, made with Q_RETURN_ARG(), receives the return value.

type is how the call is made: with Qt::DirectConnection the method runs before the function returns, and with Qt::QueuedConnection it runs from the event loop of the thread of obj, with copies of the arguments. Qt::AutoConnection calls directly when obj lives in the calling thread and queues otherwise. Qt::BlockingQueuedConnection queues the call to another thread and waits for it, so it can return a value. A queued call cannot return a value, and its argument types must be registered with QMetaType.

QString result;
QMetaObject::invokeMethod(obj, "describe", Qt::DirectConnection,
                          Q_RETURN_ARG(QString, result), Q_ARG(int, 3));

The function prints a warning and returns false if obj has no such method or the argument types do not match.

See also QMetaMethod::invoke().

[static] QByteArray QMetaObject::normalizedSignature(const char *method)

Returns method as a normalized signature: no whitespace except in type names that need it, const and & removed from by-value and const-reference parameters, and the spelled-out names of fundamental types abbreviated. For example, "setValue( const QString & , unsigned int )" becomes "setValue(QString,uint)".

See also normalizedType().
