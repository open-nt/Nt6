Detailed Description

allInterfaces() returns every interface, and allAddresses() is a shortcut for the addresses of all of them.

See also QNetworkAddressEntry and QHostAddress.

Differences from Qt

Linux only for now. Interface data is a snapshot taken when the list is requested. Type detection covers loopback, Ethernet, Wi-Fi and PPP.

Member Type Documentation

enum QNetworkInterface::InterfaceFlag

Describes the state and abilities of an interface.

ConstantDescription
QNetworkInterface::IsUpThe interface is administratively up.
QNetworkInterface::IsRunningThe interface has resources allocated and is operational.
QNetworkInterface::CanBroadcastThe interface works in broadcast mode.
QNetworkInterface::IsLoopBackThe interface is a loopback interface.
QNetworkInterface::IsPointToPointThe interface is a point-to-point link.
QNetworkInterface::CanMulticastThe interface supports multicast.

typedef QNetworkInterface::InterfaceFlags

The InterfaceFlags type is a typedef for QFlags<InterfaceFlag>. It stores an OR combination of InterfaceFlag values.
