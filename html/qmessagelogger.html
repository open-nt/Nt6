Detailed Description

QMessageLogger is what the qDebug(), qInfo(), qWarning(), qCritical() and qFatal() macros construct, with the file, line and function of the statement. Use the macros rather than the class:

qInfo() << "listening on port" << port;
qWarning("cannot open %s: %s", path, strerror(errno));

Each function has two forms. One takes a printf() style format string and arguments, and emits the message at once. The other takes no message and returns a QDebug stream, which emits the message when it is destroyed. Both also accept a QLoggingCategory, or a function that returns one, in front of the message; the qCDebug() family of macros does that.

A fatal message aborts the process after the handler has run.

See also QDebug, QLoggingCategory and qInstallMessageHandler().

Differences from Qt

The QT_NO_DEBUG_OUTPUT, QT_NO_INFO_OUTPUT and QT_NO_WARNING_OUTPUT macros are honoured, but QT_MESSAGELOGCONTEXT is not needed: the context is always present unless QT_NO_MESSAGELOGCONTEXT is defined.
