Detailed Description

A QVariant holds a single value of one type at a time: a number, a string, a date, a list or map of other variants, or any type registered with QMetaType. It is what makes properties, QObject::property() and QMetaProperty work with values of any type.

QVariant v = 42;
v.toInt();               // 42
v.toString();            // "42"
v = QString("hello");
v.typeId();              // QMetaType::QString

struct Point3D { int x, y, z; };
Q_DECLARE_METATYPE(Point3D)
QVariant p = QVariant::fromValue(Point3D{1, 2, 3});
Point3D q = p.value<Point3D>();

A default-constructed QVariant is invalid. A QVariant is null if it holds no value, a null pointer, or a value of a built-in type that is itself null, such as an empty QString, an invalid QDate or a null QUuid.

Conversions between types follow the table in QMetaType::convert(). The toXxx() functions convert and return a default value if the conversion is not possible; convert() changes the variant in place. A value that can be converted in either direction between two types compares equal with operator==().

A QVariant can be streamed to a QDataStream in Qt's wire format and printed with QDebug.

See also QMetaType, QSequentialIterable and QAssociativeIterable.

Differences from Qt

There is no QVariant::compare() or operator<(), no QVariant::toLocale(), toRegularExpression(), toEasingCurve(), toModelIndex() or CBOR conversions, since Nt has no such classes. The JSON classes can be stored, but convert() does not convert between them and other types; use QJsonValue::fromVariant() and QJsonValue::toVariant(). Constructors for long and unsigned long exist because Nt's qint64 is long on Linux; they store a qlonglong or qulonglong. A QVariantPair is a std::pair, as Nt has no QPair. The constructor that takes an std::in_place_type_t and fromStdVariant() are missing, and so is the QVariant::Private layout. Copies of a variant share the stored value until one is changed, but detach() and isDetached() are not part of the API.

[explicit] QVariant::QVariant(QMetaType type, const void *copy = nullptr)

Constructs a variant of the type type. If copy is not nullptr, the variant holds a copy of the value at that address; otherwise it holds a default-constructed value and is null. The variant is invalid if type is invalid or its values cannot be constructed that way. For QMetaType::QVariant the result is a copy of the QVariant at copy, or an invalid variant.

See also fromMetaType().

bool QVariant::canConvert(QMetaType targetType) const

Returns true if the variant can be converted to targetType; otherwise returns false. A true result does not promise that every value converts: a QString that does not hold a number is convertible to int, but not to a number.

See also convert() and QMetaType::convert().

template <typename T>bool QVariant::canConvert() const

Returns true if the variant can be converted to T; otherwise returns false.

See also convert() and value().

bool QVariant::convert(QMetaType targetType)

Converts the variant to targetType and returns true on success. If the conversion is not possible, the variant becomes a null value of targetType and the function returns false. Converting an invalid variant does the same.

See also canConvert() and clear().

bool QVariant::convert(int targetTypeId)

bool QVariant::isNull() const

Returns true if the variant is invalid, holds a null pointer, or holds a value that is itself null: an empty-and-null QString, QByteArray or QBitArray, a null QChar, an invalid QDate, QTime or QDateTime, a null QUuid, QRect, QSize, QPoint or QLine, or a variant created with QVariant(QMetaType) and no value. Other types are never null.

See also isValid() and clear().

bool QVariant::isValid() const

Returns true if the variant holds a value, even a null one; otherwise returns false.

See also isNull().

void QVariant::load(QDataStream &ds)

Reads the variant from the stream ds in the format of QVariant::save(). If the type has no stream operators, the stream's status is set to QDataStream::ReadCorruptData and the variant becomes invalid. Streams older than Qt_4_2 have no flag for a null value, and those older than Qt_5_0 write the first user type as 127.

See also save().

See also typeId().

Returns the type that has the name name, or Invalid if there is none. A type that is registered at run time gives UserType.

See also typeToName().

void QVariant::save(QDataStream &ds) const

Writes the variant to the stream ds: the type id (or QMetaType::User followed by the type name for a registered type), a flag that tells if the value is null, and the value itself. If the type has no stream operators, the stream's status is set to QDataStream::WriteFailed. A stream older than Qt_4_2 has no null flag, and one older than Qt_5_0 writes 127 in place of QMetaType::User, as QSettings does.

See also load().

bool QVariant::toBool() const

Returns the variant as a bool, converting it if needed. Zero, an empty string, "0" and "false" (in any case) are false; other numbers and strings are true. A variant that cannot be converted gives false.

QByteArray QVariant::toByteArray() const

Returns the variant as a QByteArray, converting it if needed. A QString converts to UTF-8. A variant that cannot be converted gives a null QByteArray.

QChar QVariant::toChar() const

Returns the variant as a QChar if it holds a character, a number that is a valid UTF-16 code unit, or a string of one character; otherwise returns a null QChar.

QDate QVariant::toDate() const

Returns the variant as a QDate, converting it if needed: a QDateTime gives its date and a QString is read as ISO 8601. A variant that cannot be converted gives an invalid QDate.

QDateTime QVariant::toDateTime() const

Returns the variant as a QDateTime, converting it if needed; see toDate(). A QDate gives the start of the day in local time.

QString QVariant::toString() const

Returns the variant as a QString, converting it if needed: numbers and bool give their text, dates and times give ISO 8601 text, a QByteArray is read as UTF-8, and an enumeration declared with Q_ENUM() gives its key. A variant that cannot be converted gives a null QString.

See also canConvert() and QMetaType::convert().

QStringList QVariant::toStringList() const

Returns the variant as a QStringList, converting it if needed. A QString gives a list of one string, and a list of variants gives the text of each element. A variant that cannot be converted gives an empty list.

QTime QVariant::toTime() const

Returns the variant as a QTime, converting it if needed; see toDate().

QUrl QVariant::toUrl() const

Type QVariant::type() const

Returns the type of the stored value as a QVariant::Type. For a type that is not a member of the enumeration it returns the QMetaType id, or UserType for a type registered at run time. Prefer typeId().

See also typeId() and metaType().

int QVariant::typeId() const

Returns the QMetaType id of the stored value, or QMetaType::UnknownType (0) if the variant is invalid.

See also metaType() and typeName().

const char * QVariant::typeName() const

Returns the name of the type of the stored value, or nullptr if the variant is invalid.

See also typeId() and typeToName().

[static] const char * QVariant::typeToName(int typeId)

Returns the name of the type with the id typeId, or nullptr if there is none.

See also nameToType().

int QVariant::userType() const

Returns the QMetaType id of the stored value; the same as typeId().

template <typename T>T QVariant::value() const

Returns the stored value converted to T, or a default-constructed T if the variant cannot be converted. If T is a pointer to a QObject-derived class and the variant holds a pointer to a QObject, the pointer is cast with dynamic_cast.

See also setValue(), fromValue(), canConvert() and convert().
