Detailed Description

QMap<Key, T> stores key-value pairs sorted by key and looks up values in logarithmic time. Each key appears at most once; inserting an existing key replaces its value. Use QMultiMap to store several values under one key. The key type needs operator<.

QMap<QString, int> ages;
ages.insert("Alice", 30);
ages["Bob"] = 25;
for (auto it = ages.begin(); it != ages.end(); ++it)
    qDebug() << it.key() << it.value();

The size, lookup, insertion, removal and iteration functions are shared with the other associative containers and behave as they do in Qt.

See also QMultiMap and QHash.

Differences from Qt

QMap is implemented on top of std::map and has no implicit sharing: copying a map copies all of its elements. Iterator invalidation follows std::map rather than Qt, and there is no keyValueBegin().
