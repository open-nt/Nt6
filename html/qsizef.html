Detailed Description

A size is specified by a width() and a height(), both stored as double. A default-constructed size is invalid, with a width and height of -1. Use QSize for integer dimensions.

Equality comparison is fuzzy: two dimensions are considered equal if they are equal within the precision of double.

See also QSize, QPointF and QRectF.

Differences from Qt

Dimensions are always double, which is what qreal is in Nt. There are no QDebug or QDataStream stream operators, no grownBy() or shrunkBy(), and scale() and scaled() have no overloads taking a separate width and height.

QSizeF QSizeF::scaled(const QSizeF &s, Qt::AspectRatioMode mode) const

Returns this size scaled to a rectangle with the given size s, according to the given mode.

If mode is Qt::IgnoreAspectRatio, or this size has a zero width or height, s is returned unchanged. With Qt::KeepAspectRatio the result fits inside s; with Qt::KeepAspectRatioByExpanding it covers s.

See also scale().
