Detailed Description

QTextStream can operate on a QIODevice, a QByteArray, a QString or a stdio FILE pointer. Use the stream operators to write values as text and read them back as words and numbers:

QFile file("numbers.txt");
if (file.open(QIODevice::WriteOnly)) {
    QTextStream out(&file);
    out << "pi = " << 3.14159 << Qt::endl;
}

Output is buffered and written to the device when the buffer fills, on flush(), and when the stream is destroyed. The formatting of numbers and fields is controlled by setIntegerBase(), setNumberFlags(), setRealNumberNotation(), setRealNumberPrecision(), setFieldWidth(), setFieldAlignment() and setPadChar(), or by the manipulators in the Qt namespace such as Qt::hex and Qt::endl.

Text on devices and byte arrays is always UTF-8.

See also QIODevice, QFile, QDataStream and QBuffer.

Differences from Qt

There is no setEncoding(), setAutoDetectUnicode(), setLocale() or setGenerateByteOrderMark(): a leading byte order mark is not detected and none is written. Numbers always use the "C" locale, with '.' as the decimal point and no group separators. Line breaks are never translated; readLine() splits on a newline character and strips one trailing carriage return. Output to a QString pointer always appends, because the string is not a seekable output device. pos() on a device is derived from the device position minus the UTF-8 size of the text that was read ahead, which is exact for valid UTF-8 input. Reading a number reads the longest valid numeric prefix, so "12abc" yields 12 and leaves "abc". There is no Qt::bom manipulator.

Member Type Documentation

enum QTextStream::FieldAlignment

Selects where padding is inserted when a value is shorter than the field width.

ConstantDescription
QTextStream::AlignLeftPad on the right side of the field.
QTextStream::AlignRightPad on the left side of the field. This is the default.
QTextStream::AlignCenterPad on both sides of the field.
QTextStream::AlignAccountingStylePad between the sign and the digits of a number, and otherwise as AlignRight.

enum QTextStream::NumberFlag

Controls how numbers are written. The NumberFlags type is a typedef for QFlags<NumberFlag>.

ConstantDescription
QTextStream::ShowBaseShow the base as a prefix (0x, 0b or 0) for hexadecimal, binary and octal numbers.
QTextStream::ForcePointAlways show the decimal point for floating-point numbers, even if there is no fractional part.
QTextStream::ForceSignAlways show the sign of numbers, even if positive.
QTextStream::UppercaseBaseUse an uppercase base prefix (0X, 0B) and uppercase INF, NAN and exponent letters.
QTextStream::UppercaseDigitsUse uppercase letters for digits above 9 in hexadecimal numbers.

typedef QTextStream::NumberFlags

The NumberFlags type is a typedef for QFlags<NumberFlag>. It stores an OR combination of NumberFlag values.

enum QTextStream::RealNumberNotation

Selects how floating-point numbers are written.

ConstantDescription
QTextStream::SmartNotationFixed or scientific notation, whichever is more compact (like printf's %g).
QTextStream::FixedNotationFixed-point notation (like %f).
QTextStream::ScientificNotationScientific notation (like %e).

enum QTextStream::Status

Describes the state of the stream.

ConstantDescription
QTextStream::OkThe stream is operating normally.
QTextStream::ReadPastEndThe stream has read past the end of the data in the device or string.
QTextStream::ReadCorruptDataThe stream read data that could not be converted to the requested type.
QTextStream::WriteFailedThe stream cannot write to the underlying device.

QTextStream::QTextStream()

Constructs a text stream with no device or string. Set one with setDevice() or setString() before using the stream.

[explicit] QTextStream::QTextStream(QIODevice *device)

Constructs a text stream that operates on device. The stream does not take ownership of the device.

See also setDevice().

[explicit] QTextStream::QTextStream(FILE *fileHandle, QIODeviceBase::OpenMode mode = QIODeviceBase::ReadWrite)

Constructs a text stream that operates on the stdio file fileHandle, opened with the given mode. The stream does not close the file. A seekable file can be repositioned with seek(); a terminal or pipe is read one line at a time.

[explicit] QTextStream::QTextStream(QString *string, QIODeviceBase::OpenMode mode = QIODeviceBase::ReadWrite)

Constructs a text stream that operates on string, using the open mode. Reading starts at the beginning of the string. Writing appends to the string and requires WriteOnly in mode. The string must outlive the stream.

See also setString().

[explicit] QTextStream::QTextStream(QByteArray *array, QIODeviceBase::OpenMode mode = QIODeviceBase::ReadWrite)

Constructs a text stream that operates on the byte array array, using the open mode. The array must outlive the stream. Text is encoded as UTF-8.

[explicit] QTextStream::QTextStream(const QByteArray &array, QIODeviceBase::OpenMode mode = QIODeviceBase::ReadOnly)

Constructs a text stream that reads from a copy of array, using the open mode. Text is decoded as UTF-8.

QTextStream::~QTextStream()

Flushes any buffered output and destroys the stream. A device given to the constructor or setDevice() is not closed.

See also flush().

bool QTextStream::atEnd() const

Returns true if there is no more data to read from the stream; otherwise returns false. For a QString, the stream is at its end when it is not open for reading or the read position is at the end.

See also read() and readLine().

qint64 QTextStream::pos() const

Returns the current position of the stream. For a device, this is the device position adjusted for the text that was read ahead and the output that is still buffered. For a QString, it is the read position as a number of UTF-16 code units. Returns 0 if there is no device or string.

See also seek().

QString QTextStream::read(qint64 maxlen)

Reads at most maxlen characters from the stream and returns them as a string. The result is shorter, or empty, if fewer characters remain or if maxlen is not positive.

See also readAll() and readLine().

QString QTextStream::readAll()

Reads the entire content of the stream from the current position and returns it as a string. The result is empty, but not null, if there is nothing left to read.

See also readLine() and read().

QString QTextStream::readLine(qint64 maxlen = 0)

Reads one line of text from the stream and returns it, without the line terminator. Lines end at a newline; one trailing carriage return is removed. If maxlen is greater than 0, at most maxlen characters are read. Returns a null string if the stream is at its end.

See also readLineInto(), readAll() and atEnd().

bool QTextStream::readLineInto(QString *line, qint64 maxlen = 0)

Reads one line of text from the stream into line, without the line terminator, and returns true. Lines end at a newline; one trailing carriage return is removed. If maxlen is greater than 0, at most maxlen characters are read. Returns false and clears line if the stream is at its end.

See also readLine() and readAll().

void QTextStream::reset()

Resets all formatting options to their defaults: right alignment, a space pad character, field width 0, no number flags, integer base 10, smart notation and precision 6. The status, device and read position are not changed.

See also Qt::reset().

void QTextStream::resetStatus()

Resets the status of the text stream to Ok.

See also status() and setStatus().

bool QTextStream::seek(qint64 pos)

Flushes buffered output, discards read-ahead text and seeks to pos. Returns true on success; otherwise returns false. For a QString, pos is a position in UTF-16 code units from 0 to the string size, and only the read position changes. For a device, the device must support seeking.

See also pos() and QIODevice::seek().

void QTextStream::setDevice(QIODevice *device)

Flushes any buffered output, then sets the I/O device to device, which can be nullptr. Any read-ahead text is discarded. The stream does not take ownership of the device.

See also device() and setString().

void QTextStream::setFieldAlignment(FieldAlignment a)

Sets the field alignment to a. The alignment applies when a field width is set.

See also fieldAlignment() and setFieldWidth().

void QTextStream::setFieldWidth(int w)

Sets the current field width to w. If w is 0, the default, no padding is added. The width applies to each value written.

See also fieldWidth(), setPadChar() and setFieldAlignment().

void QTextStream::setIntegerBase(int base)

Sets the base of integers to base, which can be 2 to 36 when writing. When reading, a base of 0 detects the base from a prefix (0x, 0b or a leading 0 for octal). Other values are treated as 10. The default is 10.

See also integerBase().

Sets the current number flags to f.

void QTextStream::setPadChar(QChar c)

Sets the pad character to c. The default is a space.

void QTextStream::setRealNumberNotation(RealNumberNotation n)

Sets the real number notation to n.

See also realNumberNotation() and setRealNumberPrecision().

void QTextStream::setRealNumberPrecision(int p)

Sets the precision of real numbers to p, the number of digits written after the decimal point for fixed and scientific notation, or significant digits for smart notation. A negative value is treated as 6, which is the default.

See also realNumberPrecision() and setRealNumberNotation().

void QTextStream::setStatus(Status status)

Sets the status of the text stream to status, unless an error was already recorded. The first error is kept until resetStatus() is called.

See also Status, status() and resetStatus().

void QTextStream::setString(QString *string, QIODeviceBase::OpenMode mode = QIODeviceBase::ReadWrite)

Flushes any buffered output, then makes the stream operate on string with the open mode. Reading starts at the beginning of the string, and writing appends to it.

See also string() and setDevice().
