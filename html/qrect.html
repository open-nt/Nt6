Detailed Description

A rectangle is stored as the coordinates of its top-left and bottom-right corners, both inclusive. For historical reasons right() is therefore left() + width() - 1 and bottom() is top() + height() - 1. Use QRectF for floating-point coordinates, where the right and bottom edges are exclusive.

A rectangle with a width or height less than 1 is empty (see isEmpty()); a default-constructed rectangle is null (see isNull()). Use normalized() to obtain an equivalent rectangle with non-negative width and height.

See also QRectF, QPoint, QSize and QMargins.

Differences from Qt

There are no QDebug or QDataStream stream operators.

[constexpr] bool QRect::contains(const QPoint &p, bool proper = false) const

Returns true if the given point p is inside or on the edge of the rectangle; otherwise returns false. If proper is true, the point must be strictly inside the rectangle, not on its edge.

[constexpr] bool QRect::contains(const QRect &o, bool proper = false) const

This is an overloaded function.

Returns true if the rectangle o is inside this rectangle; otherwise returns false. If proper is true, o must not touch the edges of this rectangle. A null rectangle never contains, and is never contained by, another rectangle.
