Detailed Description

A QWeakPointer<T> observes an object owned by QSharedPointer objects without keeping it alive. Call toStrongRef() to obtain a QSharedPointer, which is null if the object has been destroyed. QWeakPointer inherits from std::weak_ptr<T>.

See also QSharedPointer.

Differences from Qt

QWeakPointer is a thin subclass of std::weak_ptr<T>. It cannot observe a QObject directly, and has no data(), operator bool() or operator==().
