Detailed Description

A version number such as 6.5.1 is stored as a list of integer segments. Versions compare segment by segment, and a missing trailing segment counts as 0, so 1.2 and 1.2.0 compare equal.

QVersionNumber v = QVersionNumber::fromString("6.5.1-beta");
v.majorVersion();     // 6
v < QVersionNumber(6, 6); // true

See also QVersionNumber::compare().

Differences from Qt

fromString() takes a QStringView or a UTF-8 const char * rather than a QAnyStringView. There is no QTypeRevision conversion and no QDataStream operators. A segment that does not fit in an int ends parsing in fromString().

Returns the longest version number that is a prefix of both a and b.

[static] int QVersionNumber::compare(const QVersionNumber &a, const QVersionNumber &b)

Compares a and b segment by segment, treating a missing trailing segment as 0. Returns a negative number if a is smaller, 0 if they are equal and a positive number if a is greater.

[static] QVersionNumber QVersionNumber::fromString(QStringView string, qsizetype *suffixIndex = nullptr)

Parses the leading dot-separated decimal numbers of string into a version number. Parsing stops at the first character that does not belong to the version, such as a suffix like -beta. If suffixIndex is not nullptr, it is set to the index in string where the version ends. Returns a null version number if string does not start with a digit.

See also toString().

[static] QVersionNumber QVersionNumber::fromString(const char *string, qsizetype *suffixIndex = nullptr)

This is an overloaded function.

Parses string, which is interpreted as UTF-8.

bool QVersionNumber::isNormalized() const

Returns true if the version number has no trailing zero segment; otherwise returns false. A null version number is normalized.

See also normalized().

bool QVersionNumber::isNull() const

Returns true if the version number has no segments; otherwise returns false.

bool QVersionNumber::isPrefixOf(const QVersionNumber &other) const

Returns true if this version number is a prefix of other, which means all of its segments equal the first segments of other.

See also commonPrefix().

int QVersionNumber::majorVersion() const

Returns the first segment, or 0 if there is none.

See also minorVersion() and microVersion().

int QVersionNumber::microVersion() const

Returns the third segment, or 0 if there is none.

See also majorVersion() and minorVersion().

int QVersionNumber::minorVersion() const

Returns the second segment, or 0 if there is none.

See also majorVersion() and microVersion().

QVersionNumber QVersionNumber::normalized() const

Returns a copy of the version number without its trailing zero segments. For example 1.2.0.0 becomes 1.2.

See also isNormalized().

int QVersionNumber::segmentAt(qsizetype i) const

Returns the segment at index i, or 0 if i is past the last segment.

See also segmentCount().

qsizetype QVersionNumber::segmentCount() const

Returns the number of segments.

See also segments().

QList<int> QVersionNumber::segments() const

QString QVersionNumber::toString() const

Returns the segments joined with dots, for example "6.5.1". A null version number gives an empty string.

See also fromString().
