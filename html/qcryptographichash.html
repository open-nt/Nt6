Detailed Description

QCryptographicHash computes a message digest of the data added to it with addData(). Call result() to read the digest. More data may be added afterwards, and result() then returns the digest of all the data so far. For a single buffer, use the static hash() function.

QCryptographicHash h(QCryptographicHash::Sha256);
h.addData(QByteArrayView("hello "));
h.addData(QByteArrayView("world"));
QByteArray digest = h.result().toHex();

See also QMessageAuthenticationCode.

Differences from Qt

Algorithms are implemented in the library itself. The BLAKE2 algorithms (Blake2b_160 to Blake2s_256) and addDataWithoutCopy() are not available, and there is no swap(). Keccak_* and Sha3_* are the original Keccak and the standardized SHA-3 padding respectively.
